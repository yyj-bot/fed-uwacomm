# Python VM v1.5.1 API 升级说明

## 概述

本次升级将Python虚拟机端的WebSocket协议从v1.4升级到v1.5.1版本，实现完整的数据集切片分发、双重索引验证和完整性检查功能。

**升级日期**: 2025-01-30  
**协议版本**: v1.5.1  
**兼容性**: 不向后兼容v1.4的数据集管理功能

## 核心变更

### 1. 协议枚举扩展

**文件**: `websocket/message_router.py`

#### 新增协议类型
- `DATASET_LIST_QUERY` / `DATASET_LIST_RESPONSE` (v1.5新增)
- `DATASET_STATUS_QUERY` / `DATASET_STATUS_RESPONSE` (v1.5增强)
- `MESSAGE_ERROR` / `CONNECTION_ERROR` (v1.5增强)

#### 协议数量变化
- v1.4: 34个协议
- v1.5.1: 40个协议（+6个）

### 2. 数据集管理器

**文件**: `storage/dataset_manager.py` (新增)

#### 核心功能
```python
class DatasetManager:
    """数据集管理器 - v1.5.1版本"""
    
    def create_dataset(
        task_id: str,
        assigned_dataset_id: str,  # v1.5: 后端分配的ID
        slice_info: Dict[str, Any],  # v1.5.1: 切片信息
        ...
    ) -> bool
    
    def append_rows(
        batch_id: str,
        rows: List[Dict],  # v1.5.1: 包含localIndex/globalIndex
        batch_range: Dict,  # v1.5.1: 批次范围
        ...
    ) -> bool
    
    def complete_dataset(
        assigned_dataset_id: str
    ) -> Dict[str, Any]:  # v1.5.1: 返回sliceVerification
```

#### v1.5.1增强特性

**1. 切片元数据管理 (sliceInfo)**
```python
slice_info = {
    "startIndex": 0,              # 切片起始索引（全局）
    "endIndex": 1999,             # 切片结束索引（全局）
    "sliceSamples": 2000,         # 切片样本数
    "totalSamples": 10000,        # 原始数据集总样本数
    "sliceIndex": 1,              # 切片编号（1-based）
    "totalSlices": 5,             # 总切片数
    "allocationStrategy": "IID"   # 分配策略：IID/NON_IID
}
```

**2. 双重索引系统**
```python
# 每行数据包含双重索引
row = {
    "rowId": "row-001",
    "localIndex": 0,    # 本地索引（相对于VM切片，从0开始）
    "globalIndex": 0,   # 全局索引（相对于原始数据集）
    "data": { ... }
}

# 验证公式
assert globalIndex == localIndex + sliceInfo["startIndex"]
```

**3. 批次范围定位 (batchRange)**
```python
batch_range = {
    "localStartIndex": 0,      # 本地批次起始索引
    "localEndIndex": 199,      # 本地批次结束索引
    "globalStartIndex": 0,     # 全局批次起始索引
    "globalEndIndex": 199      # 全局批次结束索引
}
```

**4. 完整性验证 (sliceVerification)**
```python
slice_verification = {
    "expectedStartIndex": 0,
    "expectedEndIndex": 1999,
    "expectedSamples": 2000,
    "actualStartIndex": 0,
    "actualEndIndex": 1999,
    "actualSamples": 2000,
    "isComplete": True,         # 是否完整
    "missingIndices": [],       # 缺失的全局索引列表
    "continuityCheck": {        # 连续性检查
        "hasGaps": False,       # 是否存在间隙
        "gapRanges": []         # 间隙范围列表
    }
}
```

### 3. SQLite存储扩展

**文件**: `storage/sqlite_storage.py`

#### 新增数据库表

**datasets表** - 存储数据集元信息
```sql
CREATE TABLE datasets (
    assigned_dataset_id TEXT PRIMARY KEY,
    task_id TEXT NOT NULL,
    dataset_name TEXT,
    dataset_type TEXT,
    status TEXT DEFAULT 'PENDING',
    expected_rows INTEGER DEFAULT 0,
    actual_rows INTEGER DEFAULT 0,
    start_index INTEGER,        -- v1.5.1: 切片起始索引
    end_index INTEGER,          -- v1.5.1: 切片结束索引
    allocation_strategy TEXT,   -- v1.5.1: 分配策略
    slice_info TEXT,            -- v1.5.1: 完整切片信息JSON
    metadata TEXT,
    schema TEXT,
    created_at TIMESTAMP,
    completed_at TIMESTAMP
)
```

**dataset_rows表** - 存储数据集行数据
```sql
CREATE TABLE dataset_rows (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    assigned_dataset_id TEXT NOT NULL,
    batch_id TEXT,
    row_id TEXT,
    local_index INTEGER,        -- v1.5.1: 本地索引
    global_index INTEGER,       -- v1.5.1: 全局索引
    row_data TEXT NOT NULL,
    created_at TIMESTAMP,
    FOREIGN KEY (assigned_dataset_id) REFERENCES datasets(assigned_dataset_id)
)
```

#### 新增存储方法
- `save_dataset()` - 保存数据集信息
- `save_dataset_rows()` - 保存数据集行
- `update_dataset_status()` - 更新数据集状态
- `get_dataset_info()` - 获取数据集信息
- `get_dataset_rows()` - 获取数据集行（支持全局索引范围查询）
- `verify_dataset_completeness()` - 验证数据集完整性
- `delete_dataset()` - 删除数据集

### 4. 消息处理器更新

**文件**: `websocket/message_router.py`

#### 更新的处理器方法

**DATASET_LIST_QUERY处理** (v1.5新增)
```python
def _handle_dataset_list_query(self, message):
    """处理数据集列表查询"""
    datasets = dataset_manager.get_available_datasets(
        scope=query_scope,      # ALL/AVAILABLE/READY
        include_metadata=True
    )
    self._send_dataset_list_response(datasets, len(datasets))
```

**DATASET_CREATE处理** (v1.5.1增强)
```python
def _handle_dataset_create(self, message):
    """处理数据集创建 - 支持sliceInfo"""
    slice_info = data.get("sliceInfo")  # v1.5.1新增
    dataset_manager.create_dataset(
        assigned_dataset_id=data["assignedDatasetId"],
        slice_info=slice_info,
        ...
    )
```

**DATASET_APPEND_ROWS处理** (v1.5.1增强)
```python
def _handle_dataset_append_rows(self, message):
    """处理数据集追加 - 支持batchRange和双重索引"""
    batch_range = data.get("batchRange")  # v1.5.1新增
    rows = data.get("rows")  # 包含localIndex和globalIndex
    dataset_manager.append_rows(
        batch_id=batch_id,
        rows=rows,
        batch_range=batch_range
    )
```

**DATASET_COMPLETE处理** (v1.5.1增强)
```python
def _handle_dataset_complete(self, message):
    """处理数据集完成 - 返回sliceVerification"""
    result = dataset_manager.complete_dataset(assigned_dataset_id)
    slice_verification = result.get("slice_verification")  # v1.5.1
    self._send_dataset_complete_response(
        slice_verification=slice_verification,
        ...
    )
```

#### 新增响应发送方法
- `_send_dataset_list_response()` (v1.5)
- `_send_dataset_create_ack()` (v1.5.1增强)
- `_send_dataset_append_rows_ack()` (v1.5.1增强)
- `_send_dataset_complete_response()` (v1.5.1增强)
- `_send_dataset_status_response()` (v1.5)
- `_send_dataset_delete_ack()`

### 5. 任务配置验证更新

**破坏性变更**: 完全移除对`datasetId`的支持

**v1.4配置** (已移除):

```python
{
    "localTrainingConfig": {
        "datasetId": "dataset-abc123"  # ❌ v1.5中完全移除
    }
}
```

**v1.5.1配置** (新标准):
```python

    "dataConfig": {
        "assignedDatasetId": "dataset-uuid-from-backend"  # ✅ v1.5+必需
    }
}
```

## 完整性验证流程

### 数据接收流程

```
1. DATASET_CREATE
   └─> 保存slice_info
   └─> 记录expected范围: [startIndex, endIndex]

2. DATASET_APPEND_ROWS (多批次)
   └─> 验证batchRange在切片范围内
   └─> 验证每行的双重索引一致性
   └─> 记录received_indices集合

3. DATASET_COMPLETE
   └─> 执行完整性验证
   └─> 生成sliceVerification对象
   └─> 返回验证结果
```

### 验证项目

1. **样本数验证**
   ```python
   actualSamples == expectedSamples
   ```

2. **索引范围验证**
   ```python
   actualStartIndex == expectedStartIndex
   actualEndIndex == expectedEndIndex
   ```

3. **缺失数据检测**
   ```python
   expected_set = set(range(startIndex, endIndex + 1))
   missing_indices = expected_set - received_indices
   ```

4. **连续性检查**
   ```python
   # 检测索引间隙
   for i in range(len(indices) - 1):
       if indices[i+1] - indices[i] > 1:
           gap_detected = True
   ```

5. **双重索引一致性**
   ```python
   globalIndex == localIndex + startIndex
   ```

## 使用示例

### 初始化数据集管理器

```python
from feduwacomm.ml.storage import DatasetManager, VMStorage

# 创建存储管理器
storage = VMStorage("vm_storage.db")

# 创建数据集管理器
dataset_manager = DatasetManager(storage_manager=storage)

# 在WebSocket客户端中使用
client.dataset_manager = dataset_manager
```

### 处理数据集创建

```python
# 接收DATASET_CREATE消息
success = dataset_manager.create_dataset(
    task_id="fedtask-123456",
    assigned_dataset_id="backend-uuid-generated-id",
    dataset_name="acoustic_features_v1",
    dataset_type="ACOUSTIC",
    expected_rows=2000,
    slice_info={
        "startIndex": 0,
        "endIndex": 1999,
        "sliceSamples": 2000,
        "totalSamples": 10000,
        "sliceIndex": 1,
        "totalSlices": 5,
        "allocationStrategy": "IID"
    },
    metadata={"source": "bellhop_simulation"},
    schema={"frequency": "float", "depth": "float"}
)
```

### 追加数据行

```python
# 接收DATASET_APPEND_ROWS消息
success = dataset_manager.append_rows(
    task_id="fedtask-123456",
    assigned_dataset_id="backend-uuid-generated-id",
    batch_id="batch-001",
    rows=[
        {
            "rowId": "row-001",
            "localIndex": 0,
            "globalIndex": 0,
            "data": {
                "frequency": 1000.0,
                "depth": 50.0,
                "transmission_loss": 65.5
            }
        },
        # ... 更多行
    ],
    batch_range={
        "localStartIndex": 0,
        "localEndIndex": 199,
        "globalStartIndex": 0,
        "globalEndIndex": 199
    }
)
```

### 完成数据集并验证

```python
# 完成数据集接收
result = dataset_manager.complete_dataset(
    task_id="fedtask-123456",
    assigned_dataset_id="backend-uuid-generated-id"
)

# 检查验证结果
slice_verification = result.get("slice_verification")
if slice_verification.get("isComplete"):
    print("数据集接收完整 ✓")
else:
    missing_count = len(slice_verification.get("missingIndices", []))
    print(f"数据集不完整，缺失 {missing_count} 个样本")
    print(f"缺失索引: {slice_verification.get('missingIndices')[:10]}")
```

## 性能优化

### 数据库索引

v1.5.1添加了以下索引以提升查询性能:

```sql
-- 数据集索引
CREATE INDEX idx_datasets_task_id ON datasets(task_id)
CREATE INDEX idx_datasets_status ON datasets(status)

-- 数据行索引
CREATE INDEX idx_dataset_rows_dataset_id ON dataset_rows(assigned_dataset_id)
CREATE INDEX idx_dataset_rows_global_index ON dataset_rows(assigned_dataset_id, global_index)
```

### 内存优化

- 使用`received_indices`集合而非列表，提升查找性能
- 缺失索引和间隙范围限制返回数量（最多100个和20个）
- 批次信息存储轻量级元数据而非完整数据

## 故障排查

### 常见问题

**1. 数据集管理器未初始化**
```
错误: 数据集管理器未初始化
解决: 在WebSocket客户端初始化时创建dataset_manager实例
```

**2. 索引验证失败**
```
错误: 索引不一致: local=100, global=150, expected_global=100
解决: 检查后端是否正确计算globalIndex = localIndex + startIndex
```

**3. 切片范围超出**
```
错误: 批次范围 [2000-2199] 超出切片范围 [0-1999]
解决: 检查后端的数据切分逻辑，确保不同VM的范围不重叠
```

**4. 数据不完整**
```
警告: 数据集不完整: 缺失50个样本
解决: 
  - 检查网络连接是否稳定
  - 查看sliceVerification.missingIndices定位缺失数据
  - 考虑实现断点续传机制
```
