### 2. 核心协议处理方法

#### GRADIENT_UPLOAD处理器示例
```java
private ProtocolAck onGradientUpload(ProtocolMessage msg) {
    Map<String, Object> data = msg.getData();
    String vmId = msg.getVmId();
    String taskId = valueAsString(data, "taskId");
    Integer round = numberAsInt(data, "round");

    // 提取训练结果数据
    @SuppressWarnings("unchecked")
    Map<String, Object> trainingResult = (Map<String, Object>) data.get("training_result");

    if (trainingResult != null) {
        // 处理模型参数和元数据
        processGradientData(vmId, taskId, round, trainingResult);

        // 触发聚合检查
        triggerAggregationCheck(taskId, round);
    }

    return ackFor(msg, ProtocolType.GRADIENT_UPLOAD_ACK, Map.of(
        "status", "RECEIVED",
        "taskId", taskId,
        "round", round,
        "timestamp", Instant.now().toString()
    ));
}
```

### 3. 聚合服务集成

#### FederatedAggregationService增强
```java
@Service
public class FederatedAggregationService {

    private final SimpMessagingTemplate messagingTemplate;
    private final WebSocketProtocolService protocolService;

    // 聚合完成后自动发送WebSocket通知
    private void onAggregationCompleted(String taskId, GlobalModel globalModel) {
        // 发送AGGREGATION_COMPLETE通知
        broadcastAggregationComplete(taskId, globalModel);

        // 广播全局模型
        broadcastGlobalModel(taskId, globalModel);
    }

    private void broadcastAggregationComplete(String taskId, GlobalModel globalModel) {
        Map<String, Object> message = MessageBuilder.createMessage(
            ProtocolType.AGGREGATION_COMPLETE);
        message.put("taskId", taskId);
        message.put("round", globalModel.getRoundNumber());
        message.put("globalModelId", globalModel.getId());

        List<String> activeVms = getActiveVmIds(taskId);
        for (String vmId : activeVms) {
            messagingTemplate.convertAndSend("/topic/vm/" + vmId, message);
        }
    }
}
```
