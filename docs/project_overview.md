# FedUWAComm 项目概述

## 📋 项目简介

FedUWAComm是一个基于联邦学习的水声通信优化与隐私保护系统。项目致力于通过机器学习技术提升水声通信网络的性能，同时实现数据隐私保护。系统结合真实海洋环境数据与仿真信道，采用随机森林算法和联邦学习框架，动态优化通信参数，提升网络效率与安全性。

### 🎯 应用领域

- **海洋监测**: 海洋环境监测、海洋生物研究
- **水下机器人通信**: 自主水下航行器(AUV)、遥控水下航行器(ROV)
- **军事国防**: 水下通信、海洋侦察
- **水下物联网**: 海洋传感器网络、海底观测系统

## 🛠️ 技术路线

### 1. 水声信道仿真与数据采集

- **BELLHOP模型**: 利用BELLHOP水声传播模型进行信道仿真
- **环境参数**: 结合公开海洋数据集（WOA、GEBCO）获取海水深度、声速剖面、海底特性等
- **数据生成**: 生成传播损失、射线路径等水声信道仿真数据
- **数据存储**: 标准化、归一化处理后存储于MySQL数据库

### 2. 机器学习模型训练与优化

- **算法选择**: 采用随机森林算法进行回归与分类任务建模
- **特征工程**: 多粒度特征工程（时序特征提取、混合编码、局部敏感哈希LSH）
- **隐私保护**: 引入差分隐私（DP）机制保护特征重要性参数
- **模型监控**: 利用袋外误差（OOB）监控过拟合

### 3. 联邦学习框架设计与实现

- **中心服务器**: 基于SpringBoot构建，负责模型初始化、参数聚合与分发
- **本地训练**: 各节点本地训练模型，仅上传加密后的参数
- **通信协议**: 通过WebSocket/HTTPS实现双向通信，采用JWT令牌进行安全校验
- **任务调度**: 利用SpringTask定时聚合参数，MyBatis管理数据库操作

### 4. 通信参数优化与自适应调整

- **参数优化**: 基于模型预测结果，分析信道特性，动态调整通信参数
- **技术集成**: 结合自适应均衡与OFDM技术
- **效果验证**: 通过仿真或实地测试验证优化效果
- **性能可视化**: 采用Matplotlib进行性能可视化

### 5. 数据可视化与前端交互

- **前端框架**: 采用Vue框架，结合ECharts实现数据可视化
- **交互方式**: 前后端通过Axios/HTTP接口交互
- **实时展示**: 实时获取并展示Python/Matlab生成的可视化图像

### 6. 系统测试与验证

- **测试策略**: 进行单元测试与集成测试，确保各模块功能正确、系统稳定
- **质量保证**: 输出测试报告，记录优化效果
- **知识产权**: 申报软件著作权
