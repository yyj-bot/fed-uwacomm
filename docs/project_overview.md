# 项目概述（Project Overview）

## 一、项目简介

本项目致力于通过联邦学习与机器学习技术，提升水声通信网络的性能，并实现数据隐私保护。项目结合真实海洋环境数据与仿真信道，采用随机森林算法和联邦学习框架，动态优化通信参数，提升网络效率与安全性。系统广泛适用于海洋监测、水下机器人通信、军事国防及水下物联网等领域。

## 二、项目技术路线

1. **水声信道仿真与数据采集**
   - 利用 BELLHOP 模型结合公开海洋数据集（如 WOA、GEBCO），获取海水深度、声速剖面、海底特性等环境参数。
   - 生成水声信道仿真数据（如传播损失、射线路径），并进行标准化、归一化处理，存储于 MySQL 数据库。

2. **机器学习模型训练与优化**
   - 采用随机森林算法，针对水声信道预测的回归与分类任务进行建模。
   - 结合多粒度特征工程（时序特征提取、混合编码、局部敏感哈希LSH），提升模型表征能力并增强隐私保护。
   - 利用 PySpark 并行训练子树，采用袋外误差（OOB）监控过拟合，引入差分隐私（DP）机制保护特征重要性参数。

3. **联邦学习框架设计与实现**
   - 基于 SpringBoot 构建中心服务器，负责模型初始化、参数聚合与分发。
   - 各虚拟机节点本地训练模型，仅上传加密后的参数，保障数据隐私。
   - 通过 WebSocket/HTTPS 实现中心与节点的双向通信，采用 JWT 令牌进行安全校验。
   - 利用 SpringTask 定时聚合参数，MyBatis 管理数据库操作。

4. **通信参数优化与自适应调整**
   - 基于模型预测结果，分析信道特性，结合自适应均衡与 OFDM 技术，动态调整通信参数。
   - 通过仿真或实地测试验证优化效果，采用 Matplotlib 进行性能可视化。

5. **数据可视化与前端交互**
   - 前端采用 Vue 框架，结合 ECharts 实现通信优化、模型训练等数据的可视化展示。
   - 前后端通过 Axios/HTTP 接口交互，实时获取并展示 Python/Matlab 生成的可视化图像。

6. **系统测试与验证**
   - 进行单元测试与集成测试，确保各模块功能正确、系统稳定。
   - 输出测试报告，记录优化效果，申报软件著作权。

## 三、核心技术栈

- **后端开发**：SpringBoot、MyBatis、SpringTask、WebSocket、JWT、MySQL
- **机器学习/数据处理**：Python、Pandas、PySpark、Scikit-learn（随机森林）、Matplotlib
- **仿真与信道建模**：Matlab（BELLHOP）、Python
- **前端开发与可视化**：Vue、ECharts、Axios
- **安全与隐私保护**：局部敏感哈希（LSH）、差分隐私（DP）、参数加密
- **通信优化技术**：自适应均衡、OFDM

## 四、项目特色与创新点

- 联邦学习与随机森林结合，兼顾分布式训练与隐私保护。
- 多粒度特征工程与差分隐私机制，提升模型泛化能力并降低数据泄露风险。
- 动态通信参数优化，适应复杂多变的水声信道环境。
- 前后端分离，数据可视化直观，支持多种仿真与实测数据展示。
- 完整的测试与文档体系，保障系统稳定性与可维护性。
