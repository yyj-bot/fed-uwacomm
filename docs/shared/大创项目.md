## 系统架构设计

### 1. 整体架构
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   虚拟机客户端1   │    │   虚拟机客户端2   │    │   虚拟机客户端N   │
│   (Python)      │    │   (Python)      │    │   (Python)      │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         └───────────────────────┼───────────────────────┘
                                 │
                    ┌─────────────────┐
                    │  SpringBoot后端  │
                    │   (Java)        │
                    │  - 模型聚合      │
                    │  - 算法管理      │
                    │  - 数据整合      │
                    │  - 虚拟机控制    │
                    │  - 学习控制      │
                    └─────────────────┘
```

### 2. 后端服务器设计 (SpringBoot)

#### 核心模块：
- **模型管理模块**：管理全局模型和本地模型
- **聚合算法模块**：实现FedAvg、FedProx等算法
- **通信模块**：处理客户端连接和数据传输
- **数据获取模块**：从网络获取最新数据
- **安全模块**：数据加密和隐私保护
- **虚拟机控制模块**：统一管理虚拟机生命周期
- **学习控制模块**：控制学习算法和训练过程

#### 主要API端点：
- **联邦学习API**：注册客户端、提交模型、获取全局模型、聚合模型
- **虚拟机管理API**：启动/停止/重启虚拟机、获取虚拟机状态、列出所有虚拟机
- **学习控制API**：开始/停止/暂停/恢复学习、更改算法、获取学习状态和进度

### 3. 虚拟机控制模块

#### 3.1 WebSocket通信架构
采用WebSocket双向通信协议实现服务器与虚拟机之间的实时通信。WebSocket配置支持跨域访问和SockJS兼容性，确保在各种网络环境下的稳定连接。

服务器端维护虚拟机会话映射表，实时跟踪所有连接的虚拟机状态。当虚拟机连接建立时，系统记录连接时间和状态信息；当连接断开时，系统更新虚拟机状态并记录断开时间。

消息处理机制支持多种消息类型：状态更新、训练进度、模型更新、错误报告等。系统能够向单个虚拟机发送命令，也支持向所有虚拟机广播命令。

#### 3.2 虚拟机控制服务
虚拟机控制服务负责处理虚拟机的生命周期管理。通过WebSocket发送加密命令到目标虚拟机，包括启动、停止、重启等操作。每个命令都包含时间戳和数字签名，确保命令的完整性和安全性。

系统支持针对单个虚拟机的精确控制，也支持批量操作。当发送命令后，系统会更新数据库中的虚拟机状态，并等待虚拟机返回执行结果。

#### 3.3 加密服务
采用RSA非对称加密算法确保通信安全。系统使用私钥对命令进行数字签名，使用公钥验证命令的真实性。所有敏感数据都经过加密处理，确保在传输过程中的安全性。

加密服务支持命令签名验证、数据加密解密等功能。系统定期更新密钥对，确保长期安全性。

#### 3.4 消息模型
定义了标准化的消息格式，包括命令消息、状态消息、进度消息等。所有消息都包含时间戳和签名信息，确保消息的完整性和可追溯性。

### 4. 学习控制模块

#### 4.1 基于WebSocket的学习控制
学习控制模块通过WebSocket协议向所有连接的虚拟机发送学习命令。系统支持统一启动所有虚拟机的训练过程，也可以针对特定虚拟机进行精确控制。

学习配置存储在Redis中，支持动态更新。系统能够实时监控学习状态，包括训练进度、算法类型、错误信息等。当需要更改学习算法时，系统会向所有虚拟机广播新的算法配置。

### 5. 客户端设计 (Python)

#### 5.1 基于WebSocket的客户端
Python客户端采用异步WebSocket连接与服务器通信。客户端在启动时建立WebSocket连接，并持续监听服务器发送的命令。

客户端支持多种命令类型：虚拟机控制命令、学习控制命令、算法切换命令等。每个命令都经过签名验证，确保命令来源的可靠性。

客户端实现了自动重连机制，当连接断开时会自动尝试重新连接。系统还实现了心跳检测，确保连接的稳定性。

#### 5.2 异步学习处理
客户端使用asyncio实现异步学习处理，支持多种联邦学习算法：FedAvg、FedProx、FedNova等。每种算法都有独立的训练逻辑和参数配置。

学习过程支持暂停、恢复、停止等操作。客户端会定期向服务器报告训练进度和状态信息，确保服务器能够实时监控学习情况。

#### 5.3 模型管理
客户端负责本地模型的训练和更新。训练完成后，客户端会将模型参数通过WebSocket发送到服务器。同时，客户端也会从服务器下载全局模型参数，用于下一轮训练。

### 6. 虚拟机状态监控

#### 6.1 实时状态监控
系统实现了基于WebSocket的实时状态监控机制。每个虚拟机都会定期向服务器报告自己的状态信息，包括运行状态、资源使用情况、训练进度等。

服务器端维护所有虚拟机的状态映射表，支持实时查询和状态变更通知。当虚拟机状态发生变化时，系统会立即更新状态信息并通知相关组件。

#### 6.2 健康检查
系统实现了自动健康检查机制，定期检测虚拟机的连接状态和响应情况。对于长时间无响应的虚拟机，系统会标记为异常状态并尝试重新连接。

### 7. 前端管理界面（下一阶段）

#### 7.1 管理界面API
提供了完整的管理界面API，支持仪表板显示、批量操作、状态监控等功能。管理员可以通过Web界面查看所有虚拟机的状态，进行批量启动、停止等操作。

系统支持实时数据展示，包括虚拟机数量、活跃虚拟机数量、学习状态、算法统计等信息。所有操作都有详细的操作日志和结果反馈。

### 8. 配置管理

#### 8.1 WebSocket配置
系统提供了完整的WebSocket配置选项，包括连接路径、最大连接数、心跳间隔等参数。支持跨域访问配置和安全策略设置。

#### 8.2 安全配置
安全配置包括密钥路径、签名算法、加密算法等参数。系统支持多种加密算法和签名方式，确保通信安全。

#### 8.3 学习算法配置
每种学习算法都有独立的配置参数，包括训练轮数、批次大小、学习率、轮次间隔等。系统支持动态调整这些参数，无需重启服务。

### 9. 高并发优化（下一阶段）

#### 9.1 连接池管理
系统实现了高效的WebSocket连接池管理，支持大量并发连接。通过连接复用和负载均衡，确保系统能够处理一万台虚拟机的高并发访问。

#### 9.2 消息队列优化
采用异步消息处理机制，避免阻塞操作。系统使用线程池处理消息，确保高并发场景下的响应性能。

#### 9.3 内存优化
实现了内存使用优化策略，包括连接对象复用、消息缓存、垃圾回收优化等。确保系统在大量虚拟机连接时保持稳定的内存使用。

### 10. 安全机制

#### 10.1 身份验证
系统实现了基于密钥的身份验证机制，确保只有授权的虚拟机能够连接到服务器。每个虚拟机都有唯一的身份标识和密钥对。

#### 10.2 数据加密
所有敏感数据都经过加密处理，包括模型参数、配置信息、状态数据等。系统使用强加密算法确保数据安全。

#### 10.3 访问控制
实现了细粒度的访问控制机制，确保虚拟机只能访问自己需要的数据和功能。系统支持权限管理和审计日志。

### 11. 监控和日志（下一阶段）

#### 11.1 系统监控
实现了全面的系统监控机制，包括连接数监控、性能指标监控、错误率监控等。系统支持告警机制，当出现异常时能够及时通知管理员。

#### 11.2 日志管理
系统实现了详细的日志记录机制，包括操作日志、错误日志、性能日志等。所有日志都支持结构化存储和查询分析。

### 12. 部署和运维（下一阶段）

#### 12.1 容器化部署
系统支持Docker容器化部署，便于在不同环境中快速部署和扩展。提供了完整的容器配置文件和环境变量设置。

#### 12.2 负载均衡
支持多实例部署和负载均衡，确保系统的高可用性。系统可以水平扩展，支持更多虚拟机的连接。

#### 12.3 备份和恢复
实现了数据备份和恢复机制，确保系统数据的安全性。支持定期备份和灾难恢复。

这个增强的架构提供了：

1. **虚拟机生命周期管理**：启动、停止、重启虚拟机
2. **统一学习控制**：从服务器控制所有客户端的训练过程
3. **算法动态切换**：运行时更改学习算法
4. **实时状态监控**：监控虚拟机状态和学习进度
5. **批量操作**：支持批量管理虚拟机
6. **WebSocket通信**：高效的实时双向通信机制
7. **安全可靠**：加密通信和身份验证
8. **高并发支持**：优化的连接管理和消息处理
9. **易于扩展**：模块化设计和标准化接口
10. **完整监控**：全面的监控和日志系统
