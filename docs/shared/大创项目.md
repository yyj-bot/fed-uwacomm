## 系统架构设计

### 1. 架构模式概述

本系统支持两种WebSocket架构模式，确保互不影响。两种架构的主要区别在于WebSocket连接方式：

- **中心化架构**：所有WebSocket通信都通过中心服务器进行
- **去中心化架构**：部分WebSocket通信可以直接连接虚拟机，但仍需要中心服务器进行协调

### 2. 中心化架构（推荐用于生产环境）

#### 2.2 通信流程
1. **虚拟机连接**：虚拟机作为WebSocket客户端连接到后端服务器
2. **客户端连接**：可视化客户端作为WebSocket客户端连接到后端服务器
3. **消息代理**：所有消息通过后端服务器进行转发和路由
4. **统一管理**：后端服务器统一管理所有连接、认证和状态

#### 2.3 特点
- **统一入口**：所有WebSocket连接都通过后端服务器
- **安全控制**：统一的认证和授权机制
- **负载均衡**：后端服务器可以处理大量并发连接
- **NAT穿透**：支持跨网络的虚拟机连接
- **状态同步**：后端服务器维护全局状态信息

#### 3.2 通信流程
1. **直接连接**：可视化客户端可以直接连接到虚拟机的WebSocket服务器
2. **虚拟局域网**：所有组件（虚拟机、客户端、后端）都在虚拟局域网中
3. **后端通信**：后端服务器可以直接与虚拟机进行WebSocket通信
4. **中心协调**：后端服务器负责模型聚合、算法管理和全局协调
5. **状态同步**：虚拟机定期向后端服务器报告状态信息
6. **灵活路由**：支持客户端-虚拟机直连和客户端-后端-虚拟机两种通信路径

#### 3.3 特点
- **低延迟**：直接连接减少网络延迟
- **高吞吐量**：减少后端服务器的网络负载
- **内网优化**：适合局域网环境部署
- **灵活连接**：支持客户端与虚拟机的直接通信
- **中心协调**：后端服务器仍负责核心业务逻辑
- **统一网络**：所有组件都在虚拟局域网中，网络通信高效
- **双向通信**：后端服务器可以直接与虚拟机通信
- **灵活路由**：支持多种通信路径，提高系统灵活性

#### 4.2 虚拟局域网扫描
```javascript
// 虚拟局域网连接管理器
class VLANWebSocketManager {
  constructor() {
    this.vlanConfig = {
      network: "192.168.1.0/24",
      gateway: "192.168.1.254",
      clientIP: "192.168.1.100",
      vmPort: 8081
    };
    this.vmConnections = new Map();
  }

  // 扫描虚拟局域网中的虚拟机
  async scanVLAN() {
    const vmList = [];
    const baseIP = "192.168.1";
    
    for (let i = 1; i <= 254; i++) {
      const ip = `${baseIP}.${i}`;
      try {
        const isVM = await this.checkVMWebSocket(ip);
        if (isVM) {
          vmList.push({
            ip: ip,
            vmId: `vm-${i.toString().padStart(3, '0')}`,
            status: 'online'
          });
        }
      } catch (error) {
        // 忽略不可达的IP
      }
    }
    
    return vmList;
  }

  // 检查IP是否为虚拟机WebSocket服务器
  async checkVMWebSocket(ip) {
    return new Promise((resolve) => {
      const ws = new WebSocket(`ws://${ip}:8081/ws/vm/check`);
      const timeout = setTimeout(() => {
        ws.close();
        resolve(false);
      }, 2000);

      ws.onopen = () => {
        clearTimeout(timeout);
        ws.close();
        resolve(true);
      };

      ws.onerror = () => {
        clearTimeout(timeout);
        resolve(false);
      };
    });
  }

  // 连接到虚拟局域网中的虚拟机
  async connectToVM(vmId, ip) {
    const client = new VMWebSocketClient(vmId, ip, 8081);
    this.vmConnections.set(vmId, client);
    
    return new Promise((resolve, reject) => {
      client.onConnect = () => resolve(client);
      client.onError = (error) => reject(error);
      client.connect();
    });
  }
}
```

### 5. 架构切换机制

#### 5.1 配置驱动切换
```javascript
// 架构配置
const ARCHITECTURE_CONFIG = {
  mode: 'centralized', // 'centralized' | 'decentralized'
  
  // 中心化架构配置
  centralized: {
    backendUrl: 'ws://backend-server:8080/ws',
    proxyMode: true,
    allTrafficThroughBackend: true
  },
  
  // 去中心化架构配置
  decentralized: {
    vlanEnabled: true,
    vlanNetwork: '192.168.1.0/24',
    vmPort: 8081,
    autoScan: true,
    backendUrl: 'ws://backend-server:8080/ws', // 仍需要中心服务器
    directConnection: true
  }
};

// 架构管理器
class ArchitectureManager {
  constructor(config) {
    this.config = config;
    this.currentMode = config.mode;
    this.connectionManager = null;
  }

  // 初始化连接管理器
  async initialize() {
    if (this.currentMode === 'centralized') {
      this.connectionManager = new CentralizedWebSocketManager(this.config.centralized);
    } else {
      this.connectionManager = new DecentralizedWebSocketManager(this.config.decentralized);
    }
    
    await this.connectionManager.initialize();
  }

  // 切换架构模式
  async switchMode(newMode) {
    if (this.currentMode === newMode) {
      return;
    }

    // 断开当前连接
    if (this.connectionManager) {
      await this.connectionManager.disconnect();
    }

    // 切换到新架构
    this.currentMode = newMode;
    await this.initialize();
  }
}
```

#### 5.2 中心化连接管理器

class CentralizedWebSocketManager {
  constructor(config) {
    this.backendUrl = config.backendUrl;
    this.proxyMode = config.proxyMode;
    this.allTrafficThroughBackend = config.allTrafficThroughBackend;

  setupEventHandlers() {

      console.log('Connected to centralized backend');
    };

    this.ws.onmessage = (event) => {
      const message = JSON.parse(event.data);
      this.handleMessage(message);
    };
  }

  // 通过后端代理发送消息到虚拟机

    const proxyMessage = {
      type: 'PROXY_MESSAGE',
      targetVM: vmId,
      data: message
    };
    this.ws.send(JSON.stringify(proxyMessage));
  }

  // 所有通信都通过后端
  async sendMessage(message) {
    this.ws.send(JSON.stringify(message));
  }
}

#### 5.3 去中心化连接管理器
```javascript
class DecentralizedWebSocketManager {
  constructor(config) {
    this.vlanEnabled = config.vlanEnabled;
    this.vlanNetwork = config.vlanNetwork;
    this.vmPort = config.vmPort;
    this.autoScan = config.autoScan;
    this.backendUrl = config.backendUrl;
    this.directConnection = config.directConnection;
    this.vmConnections = new Map();
    this.backendConnection = null;
  }

  async initialize() {
    // 连接到中心服务器（用于协调）
    this.backendConnection = new WebSocket(this.backendUrl);
    this.setupBackendEventHandlers();

    // 扫描并连接虚拟机（直接连接）
    if (this.autoScan && this.directConnection) {
      await this.scanAndConnect();
    }
  }

  setupBackendEventHandlers() {
    this.backendConnection.onopen = () => {
      console.log('Connected to backend for coordination');
    };

    this.backendConnection.onmessage = (event) => {
      const message = JSON.parse(event.data);
      this.handleBackendMessage(message);
    };
  }

  async scanAndConnect() {
    const vlanScanner = new VLANWebSocketManager();
    const vmList = await vlanScanner.scanVLAN();
    
    for (const vm of vmList) {
      try {
        const connection = await vlanScanner.connectToVM(vm.vmId, vm.ip);
        this.vmConnections.set(vm.vmId, connection);
      } catch (error) {
        console.error(`Failed to connect to ${vm.vmId}:`, error);
      }
    }
  }

  // 直接发送消息到虚拟机
  async sendToVM(vmId, message) {
    if (this.directConnection) {
      const connection = this.vmConnections.get(vmId);
      if (connection) {
        connection.send(message);
      } else {
        throw new Error(`VM ${vmId} not connected`);
      }
    } else {
      // 回退到通过后端发送
      this.backendConnection.send(JSON.stringify({
        type: 'PROXY_MESSAGE',
        targetVM: vmId,
        data: message
      }));
    }
  }

  // 发送协调消息到后端
  async sendToBackend(message) {
    this.backendConnection.send(JSON.stringify(message));
  }

  // 后端服务器也可以直接连接虚拟机
  async connectBackendToVM(vmId, ip) {
    const backendConnection = new WebSocket(`ws://${ip}:8081/ws/vm/backend`);
    this.backendVMConnections.set(vmId, backendConnection);
    
    return new Promise((resolve, reject) => {
      backendConnection.onopen = () => resolve(backendConnection);
      backendConnection.onerror = (error) => reject(error);
    });
  }
}
```

### 7. 虚拟机客户端设计 (Python)

#### 7.1 双模式支持
Python客户端支持两种连接模式：

**中心化模式**：
- 作为WebSocket客户端连接到后端服务器
- 接收服务器转发的命令和消息
- 所有通信都通过后端服务器

**去中心化模式**：
- 作为WebSocket服务器提供WebSocket服务
- 直接接收可视化客户端的命令
- 同时保持与后端服务器的连接用于协调

#### 7.2 WebSocket服务器实现
```python
import asyncio
import websockets
import json

class VMWebSocketServer:
    def __init__(self, host="0.0.0.0", port=8081):
        self.host = host
        self.port = port
        self.clients = set()
        self.backend_connection = None
        
    async def start_server(self):
        async with websockets.serve(self.handle_client, self.host, self.port):
            print(f"VM WebSocket server started on {self.host}:{self.port}")
            await asyncio.Future()  # 运行直到被中断
            
    async def handle_client(self, websocket, path):
        self.clients.add(websocket)
        try:
            async for message in websocket:
                await self.process_message(websocket, message)
        except websockets.exceptions.ConnectionClosed:
            pass
        finally:
            self.clients.remove(websocket)
            
    async def process_message(self, websocket, message):
        data = json.loads(message)
        # 处理来自客户端的消息
        # 同时可能需要转发到后端服务器进行协调
        if self.backend_connection:
            await self.backend_connection.send(json.dumps(data))
```

### 13. 架构对比总结

| 特性 | 中心化架构 | 去中心化架构 |
|------|------------|--------------|
| **WebSocket连接方式** | 全部通过后端服务器 | 部分直接连接虚拟机 |
| **中心服务器作用** | 代理所有通信 | 协调和聚合服务 |
| **网络架构** | 星型拓扑 | 虚拟局域网 |
| **网络延迟** | 较高（经过代理） | 较低（直接连接） |
| **服务器负载** | 较高（处理所有流量） | 较低（部分流量直连） |
| **部署复杂度** | 简单 | 中等（需要虚拟局域网） |
| **安全性** | 高（统一认证） | 中等（需要额外安全措施） |
| **扩展性** | 好 | 很好 |
| **通信路径** | 单一路径 | 多种路径可选 |
| **适用场景** | 生产环境、跨网络 | 内网环境、高性能需求 |

这个增强的架构提供了：

1. **双架构支持**：中心化和去中心化架构，互不影响
