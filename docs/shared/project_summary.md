# FedUWAComm 项目总结

## 📋 项目概述

FedUWAComm 是一个基于联邦学习的水声通信优化与隐私保护系统。项目采用 monorepo 架构，实现了从数据生成到模型训练的完整工作流，并提供后端基础服务以支持联邦学习与实时通信。

### 🏗️ 系统架构

本项目包含三个主要模块：

#### 🐍 Python 虚拟机模块（`python-vm/`） — ✅ 已完成
- 功能：ML 算法、BELLHOP 仿真、特征提取、模型训练
- 技术栈：Python 3.8+、scikit-learn、pandas、numpy、MySQL

#### 🖥️ 管理端前端（`frontend-admin/`） — 🚧 规划中
- 功能：系统管理界面与可视化
- 技术栈：计划采用 Vue/React + TypeScript

#### ⚙️ Spring Boot 后端（`backend-springboot/`） — ✅ 已提供基础能力（持续完善）
- 功能：RESTful API、WebSocket 实时通信、数据访问
- 技术栈：Java 17、Spring Boot 3.4、Spring Security、MyBatis、WebSocket、MySQL
