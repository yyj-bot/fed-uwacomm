# WebSocket 联邦学习流程示例文档

本目录包含基于 WebSocket 协议 v1.4 的联邦学习完整实现流程文档，采用中心化架构设计，为开发者提供详细的技术规范和实现指导。

## 架构设计理念

### 核心原则
- **后端作为"大脑"**: 控制所有状态管理、决策逻辑、任务编排
- **虚拟机作为"手脚"**: 只响应后端指令，执行训练，上报结果
- **精确任务控制**: 通过 taskId 实现任务级别的精确控制
- **多任务支持**: 单台虚拟机可同时执行多个联邦学习任务

### 简化设计
基于 v1.4 协议的简化设计移除了所有不必要的协商、通知和复杂状态管理，专注于核心的训练执行流程。

## 技术特性

### 协议版本特性
- **基于 WebSocket 协议 v1.4**: 采用简化的消息结构和流程
- **34 个核心协议消息**: 覆盖完整的联邦学习生命周期
- **中心化状态管理**: 所有状态由后端统一维护和控制

### 联邦学习支持
- **多算法支持**: FEDERATED_AVERAGING、FEDERATED_PROXIMAL、FEDERATED_NOVA、SCAFFOLD
- **多数据类型**: ACOUSTIC、ENVIRONMENT、MODEL、OTHER、TEST_DATA、SPECIAL_CHARS、LONG_TEXT
- **任务级控制**: 通过 taskId 实现精确的任务管理和多任务并发
- **动态参与者管理**: 支持虚拟机的动态加入和退出

### 系统架构优势
- **简化复杂度**: 移除了复杂的协商和状态同步机制
- **高可控性**: 后端完全控制整个训练过程
- **易于调试**: 集中化的状态管理便于问题定位
- **扩展性强**: 支持 10 台以内虚拟机的高效协调

## 实现要点

### 消息流程简化
相比传统联邦学习协议，v1.4 协议移除了：
- MODEL_TYPE_NEGOTIATION（模型类型协商）
- ALGORITHM_CONFIG（算法配置）
- TRAINING_START_COMMAND（训练开始指令）
- AGGREGATION_START/COMPLETE（聚合开始/完成通知）

### 核心工作流程
```
任务启动 → 轮次控制 → 梯度收集 → 模型聚合 → 模型广播 → 下一轮次
```

每个阶段都由后端严格控制，虚拟机只需要按指令执行。
