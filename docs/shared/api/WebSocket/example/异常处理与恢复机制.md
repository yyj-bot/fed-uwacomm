# 异常处理与恢复机制

本文档详细描述了基于WebSocket协议v1.4的联邦学习系统异常处理策略，严格遵循"后端控制一切，虚拟机只执行"的简化架构设计。

## 1. 核心设计理念

### 1.1 简化原则
- **后端决策**: 所有异常恢复决策都由后端控制
- **虚拟机报告**: 虚拟机只负责检测和报告异常，不做恢复决策
- **状态透明**: 异常状态对后端完全可见，便于统一处理
- **快速恢复**: 通过简化的流程实现快速异常恢复

### 1.2 责任划分
**后端职责**:
- 检测虚拟机异常状态
- 制定所有恢复策略
- 执行任务级异常处理
- 管理系统级容错机制

**虚拟机职责**:
- 检测本地异常情况
- 通过ERROR消息报告给后端
- 执行后端发送的恢复指令
- 维持连接稳定性

## 2. 异常分类体系

### 2.1 按影响范围分类

#### 2.1.1 虚拟机级异常
- **连接异常**: WebSocket连接中断、心跳超时
- **训练异常**: 本地训练失败、资源不足、数据错误
- **硬件异常**: CPU/内存/GPU故障
- **软件异常**: 运行时错误、依赖缺失

#### 2.1.2 任务级异常
- **聚合异常**: 模型聚合失败、数据不兼容
- **同步异常**: 轮次同步失败、参与者不足
- **配置异常**: 参数错误、算法不支持

#### 2.1.3 系统级异常
- **网络异常**: 网络分区、带宽限制
- **服务异常**: 后端服务故障、数据库连接失败
- **负载异常**: 系统过载、资源耗尽

### 2.2 按处理策略分类

#### 2.2.1 自动恢复异常
- 单个虚拟机连接中断
- 临时网络延迟
- 可恢复的训练错误

**处理方式**: 后端自动执行恢复策略，无需人工干预

#### 2.2.2 降级处理异常
- 部分虚拟机离线
- 聚合算法执行失败
- 资源不足

**处理方式**: 后端执行降级策略，继续任务执行

#### 2.2.3 暂停等待异常
- 大量虚拟机同时离线
- 网络分区导致参与者不足
- 数据库连接问题

**处理方式**: 后端暂停任务，等待条件恢复

#### 2.2.4 人工干预异常
- 任务配置错误
- 安全攻击
- 系统级故障

**处理方式**: 后端停止任务，发送告警，需要人工处理

#### 3.1.1 训练异常检测
```python
class TrainingExceptionHandler:
    def __init__(self, client):
        self.client = client
        self.exception_types = {
            "MEMORY_ERROR": "内存不足",
            "TIMEOUT_ERROR": "训练超时",
            "DATA_ERROR": "数据错误",
            "MODEL_ERROR": "模型错误",
            "RESOURCE_ERROR": "资源不足"
        }

    def handle_training_exception(self, task_id: str, round_number: int, exception: Exception):
        """处理训练异常"""
        try:
            # 1. 分类异常类型
            error_type = self._classify_exception(exception)

            # 2. 收集异常上下文
            error_context = self._collect_error_context(task_id, round_number)

            # 3. 报告给后端
            self._report_error_to_backend(task_id, round_number, error_type, str(exception), error_context)

            # 4. 暂停当前训练
            self._pause_training(task_id)

            # 5. 等待后端指令
            self._wait_for_backend_instruction(task_id)

        except Exception as e:
            logger.error(f"异常处理失败: {e}")

    def _classify_exception(self, exception: Exception) -> str:
        """分类异常类型"""
        if isinstance(exception, MemoryError):
            return "MEMORY_ERROR"
        elif isinstance(exception, TimeoutError):
            return "TIMEOUT_ERROR"
        elif isinstance(exception, ValueError):
            return "DATA_ERROR"
        elif isinstance(exception, RuntimeError):
            return "MODEL_ERROR"
        else:
            return "UNKNOWN_ERROR"

    def _collect_error_context(self, task_id: str, round_number: int) -> Dict[str, Any]:
        """收集异常上下文信息"""
        return {
            "vmId": self.client.vm_id,
            "taskId": task_id,
            "roundNumber": round_number,
            "timestamp": time.time(),
            "systemResources": self._get_system_resources(),
            "trainingProgress": self._get_training_progress(task_id),
            "memoryUsage": self._get_memory_usage(),
            "cpuUsage": self._get_cpu_usage()
        }

    def _report_error_to_backend(self, task_id: str, round_number: int, error_type: str,
                                error_message: str, context: Dict[str, Any]):
        """向后端报告错误"""
        error_report = {
            "type": "ERROR",
            "id": self.client._generate_message_id(),
            "timestamp": self.client._get_current_timestamp(),
            "vmId": self.client.vm_id,
            "data": {
                "taskId": task_id,
                "roundNumber": round_number,
                "errorType": error_type,
                "errorMessage": error_message,
                "severity": self._determine_severity(error_type),
                "context": context,
                "recoverable": self._is_recoverable(error_type)
            }
        }

        self.client._send_message(error_report)

    def _determine_severity(self, error_type: str) -> str:
        """确定错误严重程度"""
        severity_map = {
            "MEMORY_ERROR": "HIGH",
            "TIMEOUT_ERROR": "MEDIUM",
            "DATA_ERROR": "MEDIUM",
            "MODEL_ERROR": "HIGH",
            "RESOURCE_ERROR": "HIGH",
            "UNKNOWN_ERROR": "CRITICAL"
        }
        return severity_map.get(error_type, "MEDIUM")

    def _is_recoverable(self, error_type: str) -> bool:
        """判断错误是否可恢复"""
        recoverable_errors = {"TIMEOUT_ERROR", "DATA_ERROR"}
        return error_type in recoverable_errors
```

```python
class ConnectionExceptionHandler:
    def __init__(self, client):
        self.client = client
        self.reconnect_attempts = 0
        self.max_reconnect_attempts = 5
        self.reconnect_delays = [1, 2, 5, 10, 30]  # 指数退避

    def handle_connection_lost(self):
        """处理连接丢失"""
        logger.warning("WebSocket连接丢失")

        # 1. 保存当前状态
        self._save_current_state()

        # 2. 暂停所有训练任务
        self._pause_all_training_tasks()

        # 3. 启动重连流程
        self._start_reconnection()

    def _save_current_state(self):
        """保存当前状态"""
        try:
            state = {
                "vmId": self.client.vm_id,
                "activeTasks": self._get_active_tasks_state(),
                "timestamp": time.time(),
                "connectionLostAt": time.time()
            }

            state_file = f"/tmp/vm_state_{self.client.vm_id}.json"
            with open(state_file, 'w') as f:
                json.dump(state, f, indent=2)

            logger.info("虚拟机状态已保存")

        except Exception as e:
            logger.error(f"保存状态失败: {e}")

    def _start_reconnection(self):
        """启动重连流程"""
        self.reconnect_attempts = 0

        while self.reconnect_attempts < self.max_reconnect_attempts:
            try:
                delay = self.reconnect_delays[min(self.reconnect_attempts, len(self.reconnect_delays) - 1)]
                logger.info(f"重连尝试 {self.reconnect_attempts + 1}/{self.max_reconnect_attempts}，延迟 {delay} 秒")

                time.sleep(delay)

                # 尝试重新连接
                self.client.connect()

                if self.client.is_connected:
                    logger.info("重连成功")
                    self._handle_reconnection_success()
                    return True

            except Exception as e:
                logger.error(f"重连失败: {e}")

            self.reconnect_attempts += 1

        # 所有重连尝试失败
        logger.error("重连失败，等待手动干预")
        self._handle_permanent_disconnection()
        return False

    def _handle_reconnection_success(self):
        """处理重连成功"""
        try:
            # 1. 恢复保存的状态
            self._restore_saved_state()

            # 2. 发送状态同步消息
            self._send_state_sync()

            # 3. 等待后端指令决定如何恢复任务

        except Exception as e:
            logger.error(f"重连后状态恢复失败: {e}")

    def _send_state_sync(self):
        """发送状态同步消息"""
        sync_message = {
            "type": "STATE_SYNC",
            "id": self.client._generate_message_id(),
            "timestamp": self.client._get_current_timestamp(),
            "vmId": self.client.vm_id,
            "data": {
                "reconnectionTime": time.time(),
                "activeTasks": self._get_active_tasks_state(),
                "requestResync": True,
                "previousConnectionLost": True
            }
        }

        self.client._send_message(sync_message)
```

#### 3.1.3 等待状态异常处理 - **关键联邦学习场景**
虚拟机在等待全局模型期间的异常处理是联邦学习的关键场景，需要特殊考虑：

**等待状态的异常类型**:
- **等待超时**: 聚合时间过长，超出预期等待时间
- **连接中断**: 等待期间WebSocket连接断开
- **状态不一致**: 等待期间接收到非预期消息
- **资源耗尽**: 等待期间系统资源不足

**处理原则**:
```python
class WaitingStateExceptionHandler:
    """等待状态异常处理器"""

    def __init__(self, client):
        self.client = client
        self.waiting_timeout = 1800  # 30分钟超时

    def handle_waiting_timeout(self, task_id: str):
        """处理等待超时"""
        try:
            task_context = self.client.active_tasks[task_id]
            waiting_time = time.time() - task_context.get("waiting_since", 0)

            # 1. 记录超时日志
            logger.warning(f"任务 {task_id} 等待全局模型超时: {waiting_time:.2f}秒")

            # 2. 发送超时报告给后端
            timeout_message = {
                "type": "ERROR",
                "id": self.client._generate_message_id(),
                "timestamp": self.client._get_current_timestamp(),
                "vmId": self.client.vm_id,
                "data": {
                    "taskId": task_id,
                    "errorType": "WAITING_TIMEOUT",
                    "errorMessage": f"等待全局模型超时: {waiting_time:.2f}秒",
                    "waitingSince": task_context.get("waiting_since"),
                    "context": {
                        "lastRound": task_context.get("current_round"),
                        "status": "WAITING_FOR_GLOBAL_MODEL"
                    }
                }
            }

            self.client._send_message(timeout_message)

            # 3. 保持等待状态，等待后端决策
            # 不主动退出等待，完全依赖后端指令

        except Exception as e:
            logger.error(f"处理等待超时失败: {e}")

    def handle_waiting_connection_lost(self, task_id: str):
        """处理等待期间连接丢失"""
        try:
            task_context = self.client.active_tasks[task_id]

            # 1. 保存等待状态
            waiting_state = {
                "taskId": task_id,
                "status": "WAITING_FOR_GLOBAL_MODEL",
                "waitingSince": task_context.get("waiting_since"),
                "lastRound": task_context.get("current_round"),
                "connectionLostDuringWaiting": True
            }

            # 2. 保存到本地文件
            self._save_waiting_state(waiting_state)

            # 3. 重连后需要特别处理
            task_context["reconnect_waiting"] = True

            logger.info(f"任务 {task_id} 等待期间连接丢失，状态已保存")

        except Exception as e:
            logger.error(f"处理等待期间连接丢失失败: {e}")

    def handle_reconnect_during_waiting(self, task_id: str):
        """处理等待期间重连恢复"""
        try:
            # 1. 检查是否有保存的等待状态
            waiting_state = self._load_waiting_state(task_id)
            if not waiting_state:
                return

            # 2. 发送等待状态同步消息
            sync_message = {
                "type": "STATE_SYNC",
                "id": self.client._generate_message_id(),
                "timestamp": self.client._get_current_timestamp(),
                "vmId": self.client.vm_id,
                "data": {
                    "taskId": task_id,
                    "syncType": "WAITING_STATE_RECOVERY",
                    "waitingState": waiting_state,
                    "requestGlobalModelStatus": True
                }
            }

            self.client._send_message(sync_message)

            # 3. 恢复等待状态
            task_context = self.client.active_tasks[task_id]
            task_context["status"] = "WAITING_FOR_GLOBAL_MODEL"
            task_context["waiting_since"] = waiting_state["waitingSince"]

            logger.info(f"任务 {task_id} 等待状态已恢复")

        except Exception as e:
            logger.error(f"恢复等待状态失败: {e}")
```

**等待状态异常的关键原则**:
- **绝不主动退出**: 即使超时也不主动结束等待，完全依赖后端决策
- **状态保持**: 连接中断期间保持等待状态，重连后恢复
- **透明报告**: 将所有等待异常情况报告给后端
- **被动接受**: 只接受后端的恢复指令，不做自主判断

#### 3.2.1 被动恢复机制
```python
class PassiveRecoveryHandler:
    """被动恢复处理器 - 只执行后端指令"""

    def __init__(self, client):
        self.client = client

    def handle_recovery_instruction(self, message: Dict[str, Any]):
        """处理恢复指令"""
        instruction_type = message["data"].get("instructionType")
        task_id = message["data"].get("taskId")

        if instruction_type == "RETRY_TRAINING":
            self._retry_training(task_id, message["data"])
        elif instruction_type == "SKIP_ROUND":
            self._skip_round(task_id, message["data"])
        elif instruction_type == "RESTART_TASK":
            self._restart_task(task_id, message["data"])
        elif instruction_type == "ABANDON_TASK":
            self._abandon_task(task_id, message["data"])
        else:
            logger.warning(f"未知恢复指令: {instruction_type}")

    def _retry_training(self, task_id: str, instruction_data: Dict[str, Any]):
        """重试训练"""
        try:
            # 1. 获取新的训练配置
            new_config = instruction_data.get("newConfig", {})
            round_number = instruction_data.get("roundNumber")

            # 2. 应用新配置
            if new_config:
                self._apply_training_config(task_id, new_config)

            # 3. 重新开始训练
            task_context = self.client.active_tasks.get(task_id)
            if task_context and task_context["trainer"]:
                task_context["trainer"].retry_training(round_number, new_config)

            # 4. 发送重试确认
            self._send_retry_confirmation(task_id, round_number, "SUCCESS")

        except Exception as e:
            logger.error(f"重试训练失败: {e}")
            self._send_retry_confirmation(task_id, round_number, "FAILED", str(e))

    def _skip_round(self, task_id: str, instruction_data: Dict[str, Any]):
        """跳过当前轮次"""
        try:
            round_number = instruction_data.get("roundNumber")

            # 1. 停止当前训练
            task_context = self.client.active_tasks.get(task_id)
            if task_context and task_context["trainer"]:
                task_context["trainer"].stop_training()

            # 2. 更新任务状态
            task_context["status"] = "WAITING"
            task_context["current_round"] = round_number

            # 3. 发送跳过确认
            skip_confirm = {
                "type": "ROUND_SKIP_ACK",
                "id": self.client._generate_message_id(),
                "timestamp": self.client._get_current_timestamp(),
                "vmId": self.client.vm_id,
                "data": {
                    "taskId": task_id,
                    "roundNumber": round_number,
                    "status": "SUCCESS"
                }
            }

            self.client._send_message(skip_confirm)

        except Exception as e:
            logger.error(f"跳过轮次失败: {e}")

    def _restart_task(self, task_id: str, instruction_data: Dict[str, Any]):
        """重启任务"""
        try:
            # 1. 清理当前任务状态
            if task_id in self.client.active_tasks:
                task_context = self.client.active_tasks[task_id]
                if task_context.get("trainer"):
                    task_context["trainer"].cleanup()
                del self.client.active_tasks[task_id]

            # 2. 重新初始化任务
            new_config = instruction_data.get("newTaskConfig")
            if new_config:
                success = self.client._initialize_task_trainer(task_id, new_config)

                # 3. 发送重启确认
                restart_confirm = {
                    "type": "TASK_RESTART_ACK",
                    "id": self.client._generate_message_id(),
                    "timestamp": self.client._get_current_timestamp(),
                    "vmId": self.client.vm_id,
                    "data": {
                        "taskId": task_id,
                        "status": "SUCCESS" if success else "FAILED"
                    }
                }

                self.client._send_message(restart_confirm)

        except Exception as e:
            logger.error(f"重启任务失败: {e}")

    def _abandon_task(self, task_id: str, instruction_data: Dict[str, Any]):
        """放弃任务"""
        try:
            # 1. 清理任务资源
            if task_id in self.client.active_tasks:
                task_context = self.client.active_tasks[task_id]
                if task_context.get("trainer"):
                    task_context["trainer"].cleanup()
                del self.client.active_tasks[task_id]

            # 2. 清理临时文件
            self._cleanup_task_files(task_id)

            # 3. 发送放弃确认
            abandon_confirm = {
                "type": "TASK_ABANDON_ACK",
                "id": self.client._generate_message_id(),
                "timestamp": self.client._get_current_timestamp(),
                "vmId": self.client.vm_id,
                "data": {
                    "taskId": task_id,
                    "status": "SUCCESS"
                }
            }

            self.client._send_message(abandon_confirm)

        except Exception as e:
            logger.error(f"放弃任务失败: {e}")
```

#### 4.1.1 心跳超时检测
```java
@Component
public class VmHeartbeatMonitor {

    private final Map<String, Long> lastHeartbeatTimes = new ConcurrentHashMap<>();
    private final long HEARTBEAT_TIMEOUT = 60000; // 60秒超时

    @Scheduled(fixedRate = 30000) // 每30秒检查一次
    public void checkHeartbeatTimeouts() {
        long currentTime = System.currentTimeMillis();

        lastHeartbeatTimes.entrySet().removeIf(entry -> {
            String vmId = entry.getKey();
            long lastHeartbeat = entry.getValue();

            if (currentTime - lastHeartbeat > HEARTBEAT_TIMEOUT) {
                handleVmTimeout(vmId);
                return true; // 从Map中移除
            }
            return false;
        });
    }

    public void updateHeartbeat(String vmId) {
        lastHeartbeatTimes.put(vmId, System.currentTimeMillis());
    }

    private void handleVmTimeout(String vmId) {
        logger.warn("虚拟机 {} 心跳超时", vmId);

        // 1. 更新虚拟机状态
        vmInstanceMapper.updateStatus(vmId, VmStatus.OFFLINE);

        // 2. 检查受影响的任务
        List<String> affectedTasks = taskParticipantsMapper.selectTasksByVmId(vmId);

        // 3. 处理每个受影响的任务
        for (String taskId : affectedTasks) {
            handleVmTimeoutForTask(taskId, vmId);
        }

        // 4. 发送告警
        alertService.sendVmOfflineAlert(vmId, affectedTasks);
    }

    private void handleVmTimeoutForTask(String taskId, String vmId) {
        // 1. 获取任务当前状态
        FederatedTask task = federatedTaskMapper.selectById(taskId);
        if (task == null) return;

        // 2. 统计剩余活跃参与者
        int activeParticipants = countActiveParticipants(taskId) - 1; // 减去当前离线的VM
        int minRequired = task.getMinParticipants();

        // 3. 根据剩余参与者数量决定处理策略
        if (activeParticipants >= minRequired) {
            // 有足够参与者，继续任务
            removeVmFromTask(taskId, vmId);
            logger.info("任务 {} 移除离线虚拟机 {}，继续执行", taskId, vmId);
        } else {
            // 参与者不足，暂停任务
            pauseTaskDueToInsufficientParticipants(taskId, vmId);
            logger.warn("任务 {} 因虚拟机 {} 离线导致参与者不足，已暂停", taskId, vmId);
        }
    }
}
```

#### 4.1.2 错误消息处理
```java
@Component
public class VmErrorHandler {

    @EventListener
    public void handleVmError(VmErrorMessage errorMessage) {
        String vmId = errorMessage.getVmId();
        String taskId = errorMessage.getData().getTaskId();
        String errorType = errorMessage.getData().getErrorType();

        logger.error("收到虚拟机 {} 任务 {} 错误报告: {}", vmId, taskId, errorType);

        // 1. 记录错误信息
        recordErrorEvent(vmId, taskId, errorMessage);

        // 2. 分析错误严重程度
        ErrorSeverity severity = analyzeErrorSeverity(errorMessage);

        // 3. 制定恢复策略
        RecoveryStrategy strategy = determineRecoveryStrategy(taskId, vmId, errorMessage, severity);

        // 4. 执行恢复策略
        executeRecoveryStrategy(taskId, vmId, strategy);
    }

    private ErrorSeverity analyzeErrorSeverity(VmErrorMessage errorMessage) {
        String errorType = errorMessage.getData().getErrorType();
        boolean recoverable = errorMessage.getData().isRecoverable();

        if ("MEMORY_ERROR".equals(errorType) || "RESOURCE_ERROR".equals(errorType)) {
            return ErrorSeverity.HIGH;
        } else if ("TIMEOUT_ERROR".equals(errorType) || "DATA_ERROR".equals(errorType)) {
            return recoverable ? ErrorSeverity.MEDIUM : ErrorSeverity.HIGH;
        } else if ("UNKNOWN_ERROR".equals(errorType)) {
            return ErrorSeverity.CRITICAL;
        } else {
            return ErrorSeverity.MEDIUM;
        }
    }

    private RecoveryStrategy determineRecoveryStrategy(String taskId, String vmId,
                                                     VmErrorMessage errorMessage, ErrorSeverity severity) {
        String errorType = errorMessage.getData().getErrorType();

        switch (errorType) {
            case "MEMORY_ERROR":
                return createMemoryErrorRecovery(taskId, vmId);
            case "TIMEOUT_ERROR":
                return createTimeoutErrorRecovery(taskId, vmId);
            case "DATA_ERROR":
                return createDataErrorRecovery(taskId, vmId);
            case "RESOURCE_ERROR":
                return createResourceErrorRecovery(taskId, vmId);
            default:
                return createGenericErrorRecovery(taskId, vmId, severity);
        }
    }

    private RecoveryStrategy createMemoryErrorRecovery(String taskId, String vmId) {
        return RecoveryStrategy.builder()
            .action(RecoveryAction.RETRY_WITH_REDUCED_CONFIG)
            .parameters(Map.of(
                "batch_size_reduction", 0.5,
                "memory_limit_reduction", 0.7
            ))
            .maxRetries(2)
            .retryDelay(Duration.ofMinutes(2))
            .build();
    }

    private RecoveryStrategy createTimeoutErrorRecovery(String taskId, String vmId) {
        return RecoveryStrategy.builder()
            .action(RecoveryAction.EXTEND_TIMEOUT_AND_RETRY)
            .parameters(Map.of(
                "timeout_multiplier", 1.5
            ))
            .maxRetries(1)
            .retryDelay(Duration.ofMinutes(1))
            .build();
    }

    private void executeRecoveryStrategy(String taskId, String vmId, RecoveryStrategy strategy) {
        switch (strategy.getAction()) {
            case RETRY_WITH_REDUCED_CONFIG:
                sendRetryWithReducedConfig(taskId, vmId, strategy);
                break;
            case EXTEND_TIMEOUT_AND_RETRY:
                sendExtendTimeoutRetry(taskId, vmId, strategy);
                break;
            case SKIP_CURRENT_ROUND:
                sendSkipRoundInstruction(taskId, vmId);
                break;
            case REMOVE_FROM_TASK:
                removeVmFromTask(taskId, vmId);
                break;
            case PAUSE_TASK:
                pauseTask(taskId, "虚拟机异常");
                break;
        }
    }

    private void sendRetryWithReducedConfig(String taskId, String vmId, RecoveryStrategy strategy) {
        // 构建新的训练配置
        Map<String, Object> newConfig = buildReducedConfig(taskId, strategy.getParameters());

        // 发送恢复指令
        RecoveryInstruction instruction = RecoveryInstruction.builder()
            .taskId(taskId)
            .instructionType("RETRY_TRAINING")
            .newConfig(newConfig)
            .roundNumber(getCurrentRound(taskId))
            .build();

        webSocketService.sendToVm(vmId, instruction);

        logger.info("向虚拟机 {} 发送降配重试指令", vmId);
    }
}
```

#### 4.2.1 聚合失败处理
```java
@Service
public class AggregationFailureHandler {

    public void handleAggregationFailure(String taskId, int roundNumber, Exception exception) {
        logger.error("任务 {} 轮次 {} 聚合失败: {}", taskId, roundNumber, exception.getMessage());

        // 1. 分析失败原因
        FailureAnalysis analysis = analyzeFailure(exception);

        // 2. 记录失败事件
        recordAggregationFailure(taskId, roundNumber, analysis);

        // 3. 制定恢复策略
        AggregationRecoveryStrategy strategy = determineAggregationRecovery(taskId, roundNumber, analysis);

        // 4. 执行恢复策略
        executeAggregationRecovery(taskId, roundNumber, strategy);
    }

    private FailureAnalysis analyzeFailure(Exception exception) {
        if (exception instanceof DataIncompatibilityException) {
            return FailureAnalysis.builder()
                .category("DATA_INCOMPATIBILITY")
                .severity(Severity.HIGH)
                .recoverable(true)
                .recommendedAction("FILTER_INVALID_DATA")
                .build();
        } else if (exception instanceof InsufficientResourceException) {
            return FailureAnalysis.builder()
                .category("RESOURCE_INSUFFICIENT")
                .severity(Severity.MEDIUM)
                .recoverable(true)
                .recommendedAction("REDUCE_COMPLEXITY")
                .build();
        } else {
            return FailureAnalysis.builder()
                .category("UNKNOWN")
                .severity(Severity.CRITICAL)
                .recoverable(false)
                .recommendedAction("PAUSE_AND_ALERT")
                .build();
        }
    }

    private void executeAggregationRecovery(String taskId, int roundNumber,
                                          AggregationRecoveryStrategy strategy) {
        switch (strategy.getAction()) {
            case FILTER_INVALID_DATA:
                retryWithFilteredData(taskId, roundNumber);
                break;
            case REDUCE_COMPLEXITY:
                retryWithReducedComplexity(taskId, roundNumber);
                break;
            case SKIP_ROUND:
                skipCurrentRound(taskId, roundNumber);
                break;
            case PAUSE_TASK:
                pauseTaskForManualIntervention(taskId, roundNumber);
                break;
        }
    }

    private void retryWithFilteredData(String taskId, int roundNumber) {
        try {
            // 1. 获取本轮所有模型数据
            List<VmRoundModel> models = vmRoundModelMapper.selectByTaskAndRound(taskId, roundNumber);

            // 2. 过滤无效数据
            List<VmRoundModel> validModels = models.stream()
                .filter(this::validateModelData)
                .collect(Collectors.toList());

            // 3. 检查是否有足够的有效数据
            FederatedTask task = federatedTaskMapper.selectById(taskId);
            if (validModels.size() < task.getMinParticipants()) {
                logger.warn("过滤后数据不足，跳过当前轮次");
                skipCurrentRound(taskId, roundNumber);
                return;
            }

            // 4. 重新执行聚合
            GlobalModel aggregatedModel = aggregationService.executeAggregation(taskId, roundNumber, validModels);

            // 5. 广播新模型
            broadcastGlobalModel(taskId, roundNumber, aggregatedModel);

            logger.info("使用过滤数据重新聚合成功");

        } catch (Exception e) {
            logger.error("过滤数据重试失败: {}", e.getMessage());
            skipCurrentRound(taskId, roundNumber);
        }
    }

    private void skipCurrentRound(String taskId, int roundNumber) {
        try {
            // 1. 更新任务轮次状态
            updateRoundStatus(taskId, roundNumber, RoundStatus.SKIPPED);

            // 2. 通知所有参与虚拟机跳过当前轮次
            List<String> participants = getActiveParticipants(taskId);

            RoundSkipMessage skipMessage = RoundSkipMessage.builder()
                .taskId(taskId)
                .roundNumber(roundNumber)
                .reason("聚合失败")
                .nextRoundNumber(roundNumber + 1)
                .build();

            for (String vmId : participants) {
                webSocketService.sendToVm(vmId, skipMessage);
            }

            // 3. 检查是否继续下一轮
            FederatedTask task = federatedTaskMapper.selectById(taskId);
            if (roundNumber < task.getTotalRounds()) {
                // 继续下一轮
                scheduleNextRound(taskId, roundNumber + 1);
            } else {
                // 任务完成
                completeTask(taskId);
            }

            logger.info("任务 {} 轮次 {} 已跳过", taskId, roundNumber);

        } catch (Exception e) {
            logger.error("跳过轮次失败: {}", e.getMessage());
            pauseTaskForManualIntervention(taskId, roundNumber);
        }
    }
}
```

```java
@Component
public class DatabaseFailureHandler {

    private volatile boolean usingBackupMode = false;

    @EventListener
    public void handleDatabaseFailure(DatabaseConnectionException exception) {
        logger.error("数据库连接失败: {}", exception.getMessage());

        // 1. 启用缓存模式
        enableCacheOnlyMode();

        // 2. 暂停新任务创建
        pauseNewTaskCreation();

        // 3. 发送关键告警
        alertService.sendCriticalAlert("数据库连接失败", exception);

        // 4. 启动恢复监控
        scheduleRecoveryCheck();
    }

    private void enableCacheOnlyMode() {
        usingBackupMode = true;

        // 通知所有服务组件切换到缓存模式
        applicationEventPublisher.publishEvent(new CacheOnlyModeEvent());

        logger.warn("已启用仅缓存模式");
    }

    private void pauseNewTaskCreation() {
        // 暂停接受新的任务创建请求
        taskCreationService.pause("数据库不可用");

        // 通知前端服务不可用
        systemStatusService.markDatabaseUnavailable();
    }

    @Scheduled(fixedDelay = 60000) // 每分钟检查一次
    public void checkDatabaseRecovery() {
        if (usingBackupMode) {
            try {
                // 测试数据库连接
                if (testDatabaseConnection()) {
                    restoreNormalMode();
                }
            } catch (Exception e) {
                logger.debug("数据库仍不可用: {}", e.getMessage());
            }
        }
    }

    private void restoreNormalMode() {
        try {
            // 1. 禁用缓存模式
            usingBackupMode = false;
            applicationEventPublisher.publishEvent(new NormalModeRestoredEvent());

            // 2. 同步缓存数据到数据库
            syncCacheToDatabase();

            // 3. 恢复任务创建服务
            taskCreationService.resume();
            systemStatusService.markDatabaseAvailable();

            logger.info("数据库已恢复，系统回到正常模式");

        } catch (Exception e) {
            logger.error("恢复正常模式失败: {}", e.getMessage());
            // 保持缓存模式
            usingBackupMode = true;
        }
    }
}
```

## 5. 异常恢复策略

### 5.1 策略矩阵

| 异常类型 | 检测方 | 决策方 | 恢复策略 | 预期恢复时间 |
|---------|--------|--------|----------|------------|
| 虚拟机心跳超时 | 后端 | 后端 | 移除VM/暂停任务 | 立即 |
| 训练内存不足 | 虚拟机 | 后端 | 降配重试 | 1-2分钟 |
| 训练超时 | 虚拟机 | 后端 | 延长超时重试 | 30秒 |
| 聚合数据不兼容 | 后端 | 后端 | 过滤数据重试 | 2-5分钟 |
| 聚合算法失败 | 后端 | 后端 | 跳过轮次 | 30秒 |
| 网络连接中断 | 虚拟机 | 虚拟机 | 自动重连 | 1-5分钟 |
| 数据库连接失败 | 后端 | 后端 | 缓存模式 | 立即切换 |
| 系统过载 | 后端 | 后端 | 限流暂停 | 立即 |

### 5.2 恢复优先级

#### 5.2.1 P1 - 立即处理
- 数据库连接失败
- 系统安全威胁
- 大量虚拟机同时离线

#### 5.2.2 P2 - 快速处理 (< 5分钟)
- 聚合失败
- 网络分区
- 关键虚拟机离线

#### 5.2.3 P3 - 正常处理 (< 30分钟)
- 单个虚拟机训练异常
- 非关键组件故障
- 性能降级

#### 5.2.4 P4 - 延后处理
- 日志记录异常
- 监控指标异常
- 非核心功能故障

```java
@Component
public class ExceptionMetrics {

    private final MeterRegistry meterRegistry;
    private final Counter vmErrorCounter;
    private final Counter taskFailureCounter;
    private final Timer recoveryTime;
    private final Gauge systemHealth;

    public ExceptionMetrics(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;

        this.vmErrorCounter = Counter.builder("vm.errors.total")
            .description("虚拟机错误总数")
            .tag("type", "error")
            .register(meterRegistry);

        this.taskFailureCounter = Counter.builder("task.failures.total")
            .description("任务失败总数")
            .register(meterRegistry);

        this.recoveryTime = Timer.builder("recovery.duration")
            .description("异常恢复时间")
            .register(meterRegistry);

        this.systemHealth = Gauge.builder("system.health.score")
            .description("系统健康得分")
            .register(meterRegistry, this, ExceptionMetrics::calculateHealthScore);
    }

    public void recordVmError(String errorType) {
        vmErrorCounter.increment(Tags.of("error_type", errorType));
    }

    public void recordTaskFailure(String failureReason) {
        taskFailureCounter.increment(Tags.of("reason", failureReason));
    }

    public Timer.Sample startRecoveryTimer() {
        return Timer.start(meterRegistry);
    }

    private double calculateHealthScore() {
        // 基于各项指标计算系统健康得分
        double vmHealthScore = calculateVmHealthScore();
        double taskHealthScore = calculateTaskHealthScore();
        double systemResourceScore = calculateResourceScore();

        return (vmHealthScore + taskHealthScore + systemResourceScore) / 3.0;
    }
}
```
