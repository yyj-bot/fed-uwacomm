# 后端职责与实现要求

本文档详细描述了后端服务器在联邦学习过程中的核心职责和具体实现要求，强化后端作为系统"大脑"的控制角色。

## 1. 核心职责概述

后端服务器作为联邦学习的中央协调者和决策者，负责整个训练过程的完全控制：

### 1.1 主要职责
- **任务全生命周期管理**: 创建、启动、监控、停止、恢复、删除联邦学习任务
- **精确任务控制**: 通过taskId实现任务级别的精确控制和多任务并发管理
- **轮次编排与同步**: 控制训练轮次的启动、执行、完成的精确时序
- **模型聚合执行**: 执行联邦聚合算法，生成和分发全局模型
- **状态集中管理**: 维护所有虚拟机和任务的状态信息
- **决策逻辑执行**: 所有训练策略和异常处理决策
- **数据持久化**: 保存训练数据、模型版本、统计信息和日志

### 1.2 控制理念
- **完全控制**: 虚拟机不做任何主动决策，只响应后端指令
- **集中决策**: 所有训练策略、参数调整、异常处理由后端决定
- **精确调度**: 通过WebSocket消息精确控制每台虚拟机的每个任务

## 2. 详细职责与实现要求

### 2.1 任务全生命周期管理

#### 2.1.1 任务创建和启动
**职责**:
- 接收HTTP API创建的联邦学习任务
- 生成唯一的taskId并选择参与虚拟机
- 向所有参与虚拟机发送FEDERATED_TASK_START消息
- 等待所有虚拟机确认后启动第一轮训练

**实现要求**:
```java
@Service
public class FederatedTaskServiceImpl {

    // 任务启动核心逻辑
    public void startFederatedTask(String taskId) {
        // 1. 获取任务配置
        FederatedTask task = federatedTaskMapper.selectById(taskId);
        List<String> participantVmIds = getParticipantVmIds(taskId);

        // 2. 准备初始全局模型
        GlobalModel initialModel = generateInitialGlobalModel(task);

        // 3. 向所有参与虚拟机发送启动消息
        FederatedTaskStartMessage startMessage = FederatedTaskStartMessage.builder()
            .taskId(taskId)
            .federatedAlgorithm(task.getAlgorithm())
            .totalRounds(task.getTotalRounds())
            .participants(participantVmIds)
            .initialGlobalModel(initialModel)
            .localTrainingConfig(task.getConfig())
            .build();

        // 4. 广播启动消息
        for (String vmId : participantVmIds) {
            webSocketService.sendMessage(vmId, startMessage);
        }

        // 5. 更新任务状态
        task.setStatus(FederatedTaskStatus.RUNNING);
        task.setStartedAt(LocalDateTime.now());
        federatedTaskMapper.updateById(task);

        // 6. 初始化参与者状态跟踪
        initializeParticipantTracking(taskId, participantVmIds);
    }
}
```

```java
        .graceful(true)
        .saveProgress(true)

// 任务恢复
public void resumeFederatedTask(String taskId, int resumeFromRound) {

        .build();

    updateTaskStatus(taskId, FederatedTaskStatus.RUNNING);
}
```

```java
public class RoundOrchestrationService {

    public void startNewRound(String taskId, int roundNumber) {

        // 4. 初始化轮次状态跟踪

        // 5. 启动轮次超时监控
        scheduleRoundTimeout(taskId, roundNumber);
    }
```

### 2.3 模型聚合执行

#### 2.3.1 聚合算法执行
**职责**:
- 根据任务配置选择合适的聚合算法
- 执行模型聚合并计算全局性能指标
- 生成新的全局模型

**实现要求**:
```java
@Service
public class ModelAggregationService {

    public GlobalModel executeAggregation(String taskId, int roundNumber) {
        // 1. 获取任务配置
        FederatedTask task = federatedTaskMapper.selectById(taskId);
        FederatedAlgorithm algorithm = task.getAlgorithm();

        // 2. 收集所有梯度数据
        List<GradientData> gradients = collectRoundGradients(taskId, roundNumber);

        // 3. 根据算法执行聚合
        GlobalModel aggregatedModel = switch (algorithm) {
            case FEDERATED_AVERAGING -> executeFedAvg(gradients);
            case FEDERATED_PROXIMAL -> executeFedProx(gradients, task.getMu());
            case FEDERATED_NOVA -> executeFedNova(gradients);
            case SCAFFOLD -> executeScaffold(gradients);
        };

        // 4. 计算全局性能指标
        calculateGlobalMetrics(aggregatedModel, gradients);

        // 5. 保存全局模型
        aggregatedModel.setTaskId(taskId);
        aggregatedModel.setRoundNumber(roundNumber);
        globalModelMapper.insert(aggregatedModel);

        return aggregatedModel;
    }
}
```

```java
@Service
public class MultiTaskManager {

    // 获取虚拟机当前任务状态
    public VmTaskStatus getVmTaskStatus(String vmId) {
        List<TaskParticipant> activeTasks = taskParticipantsMapper
            .selectActiveTasksByVmId(vmId);

        return VmTaskStatus.builder()
            .vmId(vmId)
            .activeTasks(activeTasks.stream()
                .map(this::mapToTaskInfo)
                .collect(Collectors.toList()))
            .totalResourceUsage(calculateResourceUsage(activeTasks))
            .build();
    }

    // 检查虚拟机是否可以接受新任务
    public boolean canAcceptNewTask(String vmId, TaskResourceRequirement requirement) {
        VmTaskStatus status = getVmTaskStatus(vmId);
        return status.getTotalResourceUsage().canAccommodate(requirement);
    }
}
```

```java
@Component
public class VmStatusMonitor {

    // 处理心跳消息
    @EventListener
    public void handleHeartbeat(HeartbeatMessage heartbeat) {
        String vmId = heartbeat.getVmId();

        // 1. 更新虚拟机最后心跳时间
        vmInstanceMapper.updateLastHeartbeat(vmId, LocalDateTime.now());

        // 2. 更新资源使用情况
        updateResourceUsage(vmId, heartbeat.getData().getResourceUsage());

        // 3. 检查异常状态
        if (detectAbnormalStatus(heartbeat)) {
            handleVmAbnormalStatus(vmId, heartbeat);
        }

        // 4. 发送心跳确认
        HeartbeatAckMessage ack = createHeartbeatAck();
        webSocketService.sendMessage(vmId, ack);
    }

    // 检测离线虚拟机
    @Scheduled(fixedRate = 30000) // 每30秒检查一次
    public void detectOfflineVms() {
        List<VmInstance> onlineVms = vmInstanceMapper.selectOnlineVms();
        LocalDateTime timeout = LocalDateTime.now().minusMinutes(2);

        for (VmInstance vm : onlineVms) {
            if (vm.getLastHeartbeat().isBefore(timeout)) {
                handleVmOffline(vm.getId());
            }
        }
    }
}
```

#### 2.6.1 虚拟机异常处理
**职责**:
- 检测和处理虚拟机故障
- 决定任务的继续、暂停或重启策略
- 管理参与者列表的动态调整

**实现要求**:
```java
// 虚拟机故障处理
public void handleVmFailure(String vmId, String taskId) {
    // 1. 获取任务当前状态
    FederatedTask task = federatedTaskMapper.selectById(taskId);
    int remainingParticipants = countActiveParticipants(taskId) - 1;

    // 2. 判断是否满足最小参与者要求
    if (remainingParticipants >= task.getMinParticipants()) {
        // 继续任务，移除故障虚拟机
        removeParticipantFromTask(taskId, vmId);
        logTaskEvent(taskId, "VM_REMOVED", vmId);
    } else {
        // 暂停任务，等待修复
        pauseTask(taskId, "INSUFFICIENT_PARTICIPANTS");
        notifyAdministrator(taskId, "Task paused due to insufficient participants");
    }
}
```

```java
    @EventListener
    public void handleWebSocketMessage(WebSocketMessage message) {
        switch (message.getType()) {
            case "FEDERATED_TASK_START_ACK" ->
                handleTaskStartAck((FederatedTaskStartAckMessage) message);
            case "ROUND_START_ACK" ->
                handleRoundStartAck((RoundStartAckMessage) message);
            case "GRADIENT_UPLOAD" ->
                handleGradientUpload((GradientUploadMessage) message);
            case "GLOBAL_MODEL_BROADCAST_ACK" ->
                handleModelBroadcastAck((GlobalModelBroadcastAckMessage) message);
            case "ROUND_COMPLETE_ACK" ->
                handleRoundCompleteAck((RoundCompleteAckMessage) message);
            case "ERROR" ->
                handleErrorReport((ErrorMessage) message);
            case "HEARTBEAT" ->
                handleHeartbeat((HeartbeatMessage) message);
            default ->
                log.warn("Unknown message type: {}", message.getType());
        }
    }
}
```
