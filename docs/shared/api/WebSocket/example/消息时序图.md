# 联邦学习WebSocket消息时序图

本文档详细描述了基于WebSocket协议v1.5的联邦学习消息时序，严格遵循"后端控制一切，虚拟机只执行"的简化架构设计。v1.5版本引入了13步标准化流程和数据集关联管理功能。

## 1. 核心设计理念

### 1.1 v1.5简化原则
- **后端主导**: 所有时序控制都由后端发起和管理
- **虚拟机被动**: 虚拟机只响应后端指令，不主动发起流程
- **任务隔离**: 通过taskId实现精确的任务级控制
- **流程简化**: 移除复杂的协商和通知机制
- **数据集管理**: 🆕 统一的assignedDatasetId管理机制

### 1.2 v1.5时序特点
- **同步启动**: 后端确保所有虚拟机同步进入下一阶段
- **状态透明**: 虚拟机状态对后端完全可见
- **自动流转**: 训练完成后自动上传梯度，无需额外指令
- **数据集确认**: 🆕 数据集分发后主动确认创建状态
- **13步标准化**: 🆕 完整的4步启动+9步轮次循环

## 2. 完整联邦学习时序

### 2.1 v1.5总体时序图 (13步标准化流程)

```mermaid
sequenceDiagram
    participant Admin as 管理员
    participant Backend as 后端服务器
    participant VM1 as 虚拟机1
    participant VM2 as 虚拟机2
    participant VMN as 虚拟机N

    Note over Admin, VMN: 阶段A: 任务启动和数据集管理 (步骤1-4，一次性)
    Admin->>Backend: 创建联邦学习任务 (HTTP API)
    Note over Backend: 生成taskId和assignedDatasetId<br/>选择参与虚拟机<br/>准备初始全局模型

    Note over Backend, VMN: 步骤1: 任务启动指令
    Backend->>VM1: FEDERATED_TASK_START (包含assignedDatasetId)
    Backend->>VM2: FEDERATED_TASK_START (包含assignedDatasetId)
    Backend->>VMN: FEDERATED_TASK_START (包含assignedDatasetId)

    Note over Backend, VMN: 步骤2: 任务启动确认
    VM1->>Backend: FEDERATED_TASK_START_ACK
    VM2->>Backend: FEDERATED_TASK_START_ACK
    VMN->>Backend: FEDERATED_TASK_START_ACK

    Note over Backend: 等待所有虚拟机确认<br/>准备验证数据集状态

    Note over Backend, VMN: 步骤3: 数据集状态查询 (🆕 v1.5新增)
    Backend->>VM1: DATASET_LIST_QUERY
    Backend->>VM2: DATASET_LIST_QUERY
    Backend->>VMN: DATASET_LIST_QUERY

    Note over Backend, VMN: 步骤4: 数据集创建确认 (🆕 v1.5新增)
    VM1->>Backend: DATASET_LIST_RESPONSE (状态: CREATED)
    VM2->>Backend: DATASET_LIST_RESPONSE (状态: CREATED)
    VMN->>Backend: DATASET_LIST_RESPONSE (状态: CREATED)

    Note over Backend: 确认所有虚拟机数据集就绪<br/>准备开始第一轮训练

    Note over Admin, VMN: 阶段B: 轮次训练 (步骤5-13，循环执行)
    loop 每个训练轮次 (直到总轮次完成)
        Note over Backend, VMN: 步骤5: 轮次开始指令
        Backend->>VM1: ROUND_START
        Backend->>VM2: ROUND_START
        Backend->>VMN: ROUND_START

        Note over Backend, VMN: 步骤6: 轮次开始确认
        VM1->>Backend: ROUND_START_ACK
        VM2->>Backend: ROUND_START_ACK
        VMN->>Backend: ROUND_START_ACK

        Note over Backend: 等待所有虚拟机确认<br/>所有就绪后同步开始训练

        Note over VM1, VMN: 步骤7: 本地训练执行<br/>(虚拟机自主执行，使用assignedDatasetId对应数据集)

        Note over Backend, VMN: 步骤8: 梯度上传
        VM1->>Backend: GRADIENT_UPLOAD (包含assignedDatasetId)
        VM2->>Backend: GRADIENT_UPLOAD (包含assignedDatasetId)
        VMN->>Backend: GRADIENT_UPLOAD (包含assignedDatasetId)

        Note over Backend, VMN: 步骤9: 梯度上传确认
        Backend->>VM1: GRADIENT_UPLOAD_ACK
        Backend->>VM2: GRADIENT_UPLOAD_ACK
        Backend->>VMN: GRADIENT_UPLOAD_ACK

        rect rgba(255, 255, 0, 0.1)
            Note over VM1, VMN: 步骤10: **虚拟机进入被动等待状态**<br/>等待后端完成模型聚合<br/>只发送心跳，不执行任何主动操作
        end

        Note over Backend: 步骤11: **后端独立执行模型聚合**<br/>验证assignedDatasetId一致性<br/>执行聚合算法 (虚拟机完全不参与)

        Note over Backend, VMN: 步骤12: 全局模型广播
        Backend->>VM1: GLOBAL_MODEL_BROADCAST
        Backend->>VM2: GLOBAL_MODEL_BROADCAST
        Backend->>VMN: GLOBAL_MODEL_BROADCAST

        Note over Backend, VMN: 步骤13: 模型确认和轮次完成
        VM1->>Backend: GLOBAL_MODEL_BROADCAST_ACK
        VM2->>Backend: GLOBAL_MODEL_BROADCAST_ACK
        VMN->>Backend: GLOBAL_MODEL_BROADCAST_ACK

        Backend->>VM1: ROUND_COMPLETE
        Backend->>VM2: ROUND_COMPLETE
        Backend->>VMN: ROUND_COMPLETE

        VM1->>Backend: ROUND_COMPLETE_ACK
        VM2->>Backend: ROUND_COMPLETE_ACK
        VMN->>Backend: ROUND_COMPLETE_ACK
    end

    Note over Admin, VMN: 阶段C: 任务完成
    Note over Backend: 保存最终模型<br/>生成训练报告<br/>清理任务资源
```

## 3. 详细阶段时序

### 3.1 任务启动阶段

#### 3.1.1 任务创建和启动
```mermaid
sequenceDiagram
    participant Admin as 管理员
    participant Backend as 后端服务器
    participant VM as 虚拟机

    Admin->>Backend: POST /api/federated-tasks<br/>创建联邦学习任务

    Note over Backend: 1. 生成唯一taskId<br/>2. 选择参与虚拟机<br/>3. 准备初始全局模型<br/>4. 配置训练参数

    Backend->>VM: FEDERATED_TASK_START
    Note over Backend, VM: 消息包含:<br/>- taskId<br/>- federatedAlgorithm<br/>- totalRounds<br/>- initialGlobalModel<br/>- localTrainingConfig

    Note over VM: 1. 接收任务配置<br/>2. 加载初始全局模型<br/>3. 准备本地训练环境<br/>4. 初始化任务上下文

    VM->>Backend: FEDERATED_TASK_START_ACK
    Note over VM: 确认内容:<br/>- taskId<br/>- 初始化状态<br/>- 准备完成时间

    Note over Backend: 统计确认状态<br/>等待所有虚拟机就绪
```

**时序要求**:
- 任务启动消息发送间隔: < 1秒
- 虚拟机初始化超时: 30秒
- 所有虚拟机就绪检查间隔: 2秒

#### 3.2.1 轮次开始同步

#### 3.2.2 本地训练执行和虚拟机等待
```mermaid
sequenceDiagram
    participant Backend as 后端服务器
    participant VM as 虚拟机

    Note over Backend: 所有虚拟机发送ROUND_START_ACK<br/>训练自动开始

    Note over VM: 开始本地训练<br/>状态: TRAINING<br/>1. 使用当前全局模型<br/>2. 执行本地训练<br/>3. 计算梯度信息

    opt 训练进度报告 (可选)
        VM->>Backend: TRAINING_PROGRESS
        Note over Backend: 记录训练进度<br/>用于监控和调试
    end

    Note over VM: 训练完成<br/>1. 提取模型梯度<br/>2. 计算训练指标<br/>3. 准备上传数据

    VM->>Backend: GRADIENT_UPLOAD
    Note over Backend, VM: 上传内容:<br/>- taskId<br/>- roundNumber<br/>- gradientData<br/>- trainingMetrics<br/>- samplesCount

    Note over Backend: 1. 验证数据完整性<br/>2. 保存梯度到数据库<br/>3. 更新参与者状态

    Backend->>VM: GRADIENT_UPLOAD_ACK

    rect rgba(255, 255, 0, 0.2)
        Note over VM: **进入被动等待状态**<br/>状态: WAITING_FOR_GLOBAL_MODEL<br/>- 不执行任何主动操作<br/>- 继续发送心跳维持连接<br/>- 被动等待后端聚合完成<br/>- 完全不知道聚合进度
    end

    Note over Backend: **后端独立执行模型聚合**<br/>- 收集所有虚拟机梯度<br/>- 执行聚合算法<br/>- 生成新全局模型<br/>- 虚拟机完全不参与此过程

    Backend->>VM: GLOBAL_MODEL_BROADCAST

    rect rgba(0, 255, 0, 0.2)
        Note over VM: **结束等待状态**<br/>状态: RECEIVING_MODEL<br/>- 从等待状态恢复活跃<br/>- 接收并验证新全局模型<br/>- 准备下一轮训练
    end
```

**时序要求**:
- 轮次启动确认超时: 60秒
- 本地训练超时: 可配置 (通常10-30分钟)
- 梯度上传超时: 5分钟

## 4. 异常情况时序

### 4.1 虚拟机超时处理

```mermaid
sequenceDiagram
    participant Backend as 后端服务器
    participant VM1 as 正常虚拟机
    participant VM2 as 超时虚拟机

    Backend->>VM1: ROUND_START
    Backend->>VM2: ROUND_START

    VM1->>Backend: ROUND_START_ACK

    Note over Backend: 决策: 以可用虚拟机继续<br/>移除VM2出当前轮次

    Note over VM2: 恢复连接
    VM2->>Backend: ROUND_START_ACK (迟到)

    Backend->>VM2: ERROR (ROUND_TIMEOUT)
    Note over VM2: 等待下一轮次
```

### 4.2 网络中断恢复

```mermaid
sequenceDiagram
    participant Backend as 后端服务器
    participant VM as 虚拟机

    Note over Backend, VM: 正常通信中

    Note over Backend, VM: 网络中断

    Note over VM: 1. 检测连接丢失<br/>2. 保存训练状态<br/>3. 启动重连机制

    VM->>Backend: WebSocket重连
    VM->>Backend: CONNECT

    Backend->>VM: CONNECT_ACK

    VM->>Backend: HEARTBEAT (包含所有任务状态)

    alt 如果有任务轮次仍在进行
        Note over Backend: 该任务继续当前轮次
        VM->>Backend: GRADIENT_UPLOAD (如果训练已完成)
    else 如果任务轮次已结束
        Backend->>VM: GLOBAL_MODEL_BROADCAST (如果错过了模型更新)

    Backend->>VM: HEARTBEAT_ACK
    Note over VM: 恢复正常工作状态
```

### 4.3 聚合失败处理

```mermaid
sequenceDiagram
    participant Backend as 后端服务器
    participant AggEngine as 聚合引擎
    participant VM as 虚拟机

    Backend->>AggEngine: 启动聚合任务

    Note over AggEngine: 聚合失败:<br/>- 数据不兼容<br/>- 计算错误<br/>- 资源不足

    AggEngine->>Backend: 聚合失败通知

    Note over Backend: 错误处理策略:<br/>1. 记录错误日志<br/>2. 分析失败原因<br/>3. 决定处理方案

    alt 重试聚合
        Backend->>AggEngine: 重新启动聚合 (使用修正参数)
        Note over AggEngine: 尝试修复问题重新聚合
    else 跳过当前轮次
        Backend->>VM: ERROR (AGGREGATION_FAILED)
        Note over VM: 保持当前模型<br/>等待下一轮次
        Backend->>VM: ROUND_COMPLETE (标记轮次跳过)
    else 暂停任务
        Backend->>VM: FEDERATED_TASK_STOP
        Note over VM: 保存任务状态<br/>等待手动恢复
    end
```

### 6.2 时序监控指标

**关键时序指标**:
- 任务启动时间: 从HTTP创建到第一轮开始
- 轮次同步时间: 从ROUND_START到所有ACK
- 训练执行时间: 从轮次开始到梯度上传
- 聚合执行时间: 从收集完梯度到模型广播
- 端到端轮次时间: 完整轮次的总时间

**监控实现**:
```javascript
class TimingMonitor {
    constructor() {
        this.metrics = new Map();
    }

    startTiming(taskId, phase, round = null) {
        const key = `${taskId}-${phase}-${round || 'global'}`;
        this.metrics.set(key, {
            startTime: Date.now(),
            taskId, phase, round
        });
    }

    endTiming(taskId, phase, round = null) {
        const key = `${taskId}-${phase}-${round || 'global'}`;
        const metric = this.metrics.get(key);
        if (metric) {
            metric.duration = Date.now() - metric.startTime;
            metric.endTime = Date.now();
            return metric.duration;
        }
        return null;
    }
}
```
