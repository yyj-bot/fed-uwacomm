# 水声联邦学习系统 API 文档

## 文档概览

本目录包含了水声联邦学习系统的完整API文档，包括HTTP接口和WebSocket通信协议。

## 文档结构

### 1. HTTP接口文档
- **文件**: [HTTP接口文档.md](./HTTP/HTTP接口文档.md)
- **内容**: RESTful API接口定义，包括用户管理、模型管理、任务管理等
- **适用**: 所有HTTP客户端调用

### 2. 数据库设计文档
- **文件**: [数据库表结构文档](../database/database_schema.md)
- **内容**: 完整的数据库表结构设计，包括表关系、索引建议、数据字典等
- **适用**: 数据库设计和开发参考

### 3. WebSocket协议文档

#### 3.1 中心化实现
- **文件**: [WebSocket协议文档-中心化实现.md](./WebSocket/WebSocket协议文档-中心化实现.md)
- **内容**: 中心化WebSocket架构的详细实现方案
- **适用**: 生产环境部署

#### 3.2 去中心化实现
- **文件**: [WebSocket协议文档-去中心化实现.md](./WebSocket/WebSocket协议文档-去中心化实现.md)
- **内容**: 去中心化WebSocket架构的详细实现方案
- **适用**: 开发测试环境

#### 3.3 架构对比
- **文件**: [WebSocket协议文档-架构对比.md](./WebSocket/WebSocket协议文档-架构对比.md)
- **内容**: 两种架构模式的详细对比和选择建议
- **适用**: 架构决策参考

## 快速开始

### 数据库设计
1. 阅读 [数据库表结构文档](../database/database_schema.md) 了解数据库设计
2. 根据文档创建数据库表和索引
3. 配置数据库连接和权限

### 开发环境
1. 阅读 [WebSocket协议文档-去中心化实现.md](./WebSocket/WebSocket协议文档-去中心化实现.md)
2. 参考 [HTTP接口文档.md](./HTTP/HTTP接口文档.md) 进行API调用
3. 使用去中心化架构进行开发和测试

### 生产环境
1. 阅读 [WebSocket协议文档-中心化实现.md](./WebSocket/WebSocket协议文档-中心化实现.md)
2. 参考 [HTTP接口文档.md](./HTTP/HTTP接口文档.md) 进行API调用
3. 使用中心化架构进行生产部署

### 架构选择
1. 阅读 [WebSocket协议文档-架构对比.md](./WebSocket/WebSocket协议文档-架构对比.md)
2. 根据具体需求选择合适的架构模式
3. 参考相应的实现文档进行部署

## 技术栈

### 后端技术
- **Spring Boot**: 主要后端框架
- **WebSocket**: 实时通信协议
- **MyBatis**: 数据持久化
- **JWT**: 身份认证

### 前端技术
- **JavaScript**: 客户端实现
- **WebSocket API**: 浏览器原生支持
- **Chart.js**: 数据可视化

### 部署技术
- **Docker**: 容器化部署
- **Docker Compose**: 多服务编排
- **Systemd**: 系统服务管理
