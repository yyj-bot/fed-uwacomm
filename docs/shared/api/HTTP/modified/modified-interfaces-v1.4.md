# API接口修改文档 v1.4

## 修改概述
**版本:** v1.4
**日期:** 2025-09-28
**修改类型:** 关键Bug修复 + 接口数据格式标准化

## 主要变更

### 🚨 高优先级修复: 任务列表查询接口 SQL 语法错误
- **修复问题:** 解决数据库 SQL 语法错误 `Unknown column 'created_by' in 'where clause'`
- **影响接口:** `GET /api/federated/tasks` (任务列表查询接口)
- **修复操作:**
  - 移除 FederatedTasksMapper.xml 中对不存在字段 `created_by` 的引用
  - 更新查询条件，确保 SQL 语法正确
- **测试状态:** ✅ 已通过测试验证

### 🔧 中优先级修复: 参数验证逻辑强化
- **修复问题:** v1.3版本新格式参数验证不完整的问题
- **影响接口:** `POST /api/federated/tasks` (任务创建接口)
- **修复操作:**
  - 在 TaskCreateDTO.ParticipantConfigDTO.participants 添加 `@NotEmpty` 验证注解
  - 移除向后兼容代码，严格执行新格式验证
  - 确保 "参与者列表不能为空" 验证正常工作
- **兼容性:** 🚫 不再支持v1.0-v1.2旧格式，仅保留v1.3新格式对接

### ⚠️ 低优先级修复: VM列表接口数据格式标准化
- **修复问题:** VM列表接口返回数据字段名与API文档不一致
- **影响接口:** `GET /api/vm/list` (VM列表查询接口)
- **修复操作:**
  - PageResult类字段名从 `current` 更改为 `page`
  - PageResult类字段名从 `records` 更改为 `list`
  - 更新所有相关服务类的使用方式
- **标准化结果:** 接口返回格式现已完全符合API文档规范

## 具体接口变更

### 🔄 修复接口详情

#### 1. 任务列表查询接口修复
**接口:** `GET /api/federated/tasks`

**修复前问题:**
- SQL错误：`Unknown column 'created_by' in 'where clause'`
- 接口无法正常查询任务列表

**修复后状态:**
- ✅ 移除了对不存在字段的查询条件
- ✅ SQL语法错误已完全解决
- ✅ 任务列表查询功能正常

**技术细节:**
- 文件：`FederatedTasksMapper.xml`
- 移除：`<if test="createdBy != null and createdBy != ''">AND created_by = #{createdBy}</if>`
- 影响：所有任务查询相关的SQL语句

#### 2. 任务创建接口参数验证强化
**接口:** `POST /api/federated/tasks`

**修复前问题:**
```json
// v1.3新格式缺少严格验证
{
  "participantConfig": {
    "participants": [] // 空数组通过验证，但业务上不允许
  }
}
```

**修复后行为:**
```json
// 现在会严格验证，空数组将被拒绝
{
  "participantConfig": {
    "participants": [
      {
        "vmId": "vm-001",
        "role": "PARTICIPANT",
        "dataRatio": 0.33
      }
    ]
  }
}
```

**验证规则:**
- ✅ `@NotEmpty(message = "参与者列表不能为空")` 严格生效
- 🚫 移除向后兼容代码，不再支持v1.0-v1.2旧格式
- ✅ 确保业务逻辑的数据完整性

#### 3. VM列表接口数据格式标准化
**接口:** `GET /api/vm/list`

**修复前返回格式:**
```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "total": 10,
    "pages": 2,
    "current": 1,     // ❌ 不符合文档规范
    "size": 5,
    "records": [...]  // ❌ 不符合文档规范
  }
}
```

**修复后返回格式:**
```json
{
  "code": 200,
  "message": "查询成功",
  "data": {
    "total": 10,
    "pages": 2,
    "page": 1,       // ✅ 符合API文档规范
    "size": 5,
    "list": [...]    // ✅ 符合API文档规范
  }
}
```

**技术变更:**
- 类文件：`PageResult.java`
- 字段更名：`current` → `page`
- 字段更名：`records` → `list`
- 更新：所有使用PageResult的服务类

## 迁移指南

