🔗 接口地址

基础URL: http://localhost:8080/api/user

📋 接口列表

  • POST /register - 用户注册
  • POST /login - 用户登录
  • POST /refresh - 刷新Token
  • POST /logout - 用户登出
  • GET /profile - 获取当前用户信息
  • PUT /profile - 更新用户信息
  • PUT /password - 修改密码

🔐 认证方式

除登录、注册接口外，所有接口都需要在请求头中携带JWT Token：

Authorization: Bearer {token}

📊 响应格式

{
  "code": 200,
  "message": "success",
  "data": {}
}
