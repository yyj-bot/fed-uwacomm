🔄 虚拟机轮次模型结果 API 测试

测试虚拟机本地模型查询、分析等功能

1. 本地模型结果分页查询

接口路径: GET /api/model/vm-round-models

2. 本地模型结果详情查询

接口路径: GET /api/model/vm-round-models/{vmRoundModelId}

3. 本地模型训练指标趋势

接口路径: GET /api/model/vm-round-models/metrics/trend

4. 本地模型最佳/离群查询

接口路径: GET /api/model/vm-round-models/metrics/best

以下是一些便于测试的示例数据:

  • 虚拟机ID: vm-001, vm-002, vm-003
